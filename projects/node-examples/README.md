# Node 레슨 실행 예제

Node.js 22 이상에서 사용합니다. 각 node-XX 폴더 안에서 해당 파일을 node로 실행합니다.
- node-01: node main.mjs cafe
- node-02: node main.mjs (pricing.mjs를 가져옵니다)
- node-03: node server.mjs (4177 포트를 사용, 종료 Ctrl+C)
- node-04: node validate.mjs (기본은 정상 주문, 잘못된 인수는 파일을 수정해 시험)
- node-05: node files.mjs (이 폴더에 practice-data.json을 덮어쓰는 연습)
- node-06: node config.mjs / macOS·Linux에서 PORT=4200 node config.mjs
- node-07은 별도 cafe-lab 전체 프로젝트입니다.

서버 코드와 터미널 명령은 브라우저의 JavaScript 콘솔에 붙여 실행하는 것이 아닙니다.
