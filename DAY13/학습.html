DAY 13 / 읽기 · 수정 · 실행

카페 메뉴판 다루기

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차기초 용어·들여쓰기 안내예제만 새 탭에서 열기
기초 정의핵심 정리코드 수정·실행복습문제

01. 핵심 개념

배열은 순서, 객체는 속성, 객체 배열, JSON 변환

02. 실행 흐름

JSON 문자열 → JSON.parse → 배열·객체 읽기 → 항목 변경·출력

기초부터 천천히 읽기

서비스의 상품 목록이나 회원 정보는 하나의 숫자보다 복잡합니다. 배열로 여러 항목을 묶고, 객체로 항목의 이름과 가격 같은 속성을 묶으면 데이터 구조를 읽을 수 있습니다.

처음 보는 말의 정확한 뜻

키와 값
객체에서 name은 키, "커피"는 그 키에 연결된 값입니다. 값을 읽으려면 먼저 어느 객체의 어느 키인지 찾습니다.
점 표기법과 대괄호 표기법
menu.name은 name 속성, menu[key]는 key 변수 등에 담긴 이름의 속성을 읽습니다.
객체 배열
배열의 각 항목이 객체인 구조입니다. menus[0].name처럼 위치로 항목을 찾고 이름으로 속성을 찾습니다.
원본 변경 메서드
push·pop·splice 등은 원래 배열을 바꿉니다. 반환값이 원래 배열 전체인지도 별도로 확인합니다.
얕은 복사
배열의 바깥 구조를 복사해도 내부 객체는 같은 참조일 수 있습니다. 복사했다는 말만으로 내부 변경이 독립적이라고 단정하지 않습니다.
JSON의 제한
JSON은 데이터 형식으로 함수나 주석을 표현하지 않습니다. JavaScript 코드에서 허용되는 모든 표기를 JSON에서도 쓸 수 있는 것은 아닙니다.

기호와 문법을 읽는 법

같은 기호도 문맥에 따라 역할이 달라집니다. 아래 설명은 이 페이지의 예제 기준입니다.

짧은 코드 한 줄씩 읽기

const menus = [
  { name: "커피", price: 4000 },
  { name: "빵", price: 3500 }
];

console.log(menus[1].name);
  1. 대괄호 안에 객체 두 개가 있습니다. 각 객체의 속성은 name과 price입니다.
  2. menus[1]은 두 번째 객체를 고릅니다. 배열 번호는 0부터 시작합니다.
  3. 그 객체의 .name을 읽으므로 문자열 "빵"을 얻습니다.

예상 결과와 전제

콘솔에 빵이 출력됩니다. menus[0].price로 바꾸면 숫자 4000이 출력됩니다.

아래 실행 편집기에는 실행 가능한 전체 예제가 있습니다. 위 짧은 코드는 개념 설명용 발췌이며, 필요한 주변 코드와 전제를 함께 읽어 주세요.

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

배열
여러 값을 순서대로 담는 자료구조입니다. []로 만들고 인덱스로 항목을 읽습니다.
인덱스와 length
인덱스는 0부터 세는 위치입니다. length는 항목 수이며 마지막 위치는 length - 1입니다.
객체
이름과 값의 묶음입니다. { name: "커피", price: 4000 }처럼 항목의 정보를 표현합니다.
속성 접근
menu.name은 고정된 속성 이름을 읽고, menu[key]는 변수에 담긴 이름 등으로 속성을 읽을 수 있습니다.
JSON
데이터를 주고받거나 저장할 때 쓰는 문자열 형식입니다. JavaScript 객체 자체와는 다릅니다.
stringify / parse
JSON.stringify는 값을 JSON 문자열로, JSON.parse는 JSON 문자열을 JavaScript 값으로 바꿉니다.

꼭 기억할 내용

  • menus[1]은 두 번째 메뉴이고 menus[1].price는 그 메뉴의 가격입니다.
  • const 배열·객체도 내부 속성은 바뀔 수 있습니다. React state로 쓸 때는 별도로 불변성을 지켜야 합니다.
  • JSON은 속성 이름과 문자열에 큰따옴표를 사용합니다. 마지막 쉼표나 함수를 넣을 수 없습니다.
이 예제의 코드를 읽는 순서
  1. 객체 두 개가 menus 배열에 들어 있습니다.
  2. 두 번째 객체의 price를 3800으로 바꿉니다.
  3. 배열을 JSON 문자열로 바꾼 뒤 다시 배열로 복원합니다.
  4. 복원한 값의 두 번째 이름과 전체 내용을 출력합니다.

자주 헷갈리는 부분

JSON 문자열에서 바로 .price를 읽을 수 있을까요?

문자열과 객체를 구분하세요. JSON.parse로 값으로 바꾼 뒤 구조에 맞게 접근합니다.

slice와 splice는 같은 동작일까요?

slice는 일부를 복사한 새 배열을 만들고, splice는 원래 배열에서 삭제·추가 등을 수행합니다.

03. 직접 바꿔 보기

두 번째 메뉴 가격을 3800에서 4200으로 바꿔 보세요.

먼저 결과를 예상하고 한두 줄만 바꿔 보세요. 화면 편집 내용은 이 브라우저에 자동 저장됩니다. 브라우저가 저장을 제한하면 저장되지 않을 수 있습니다.

코드는 안쪽 단계마다 두 칸씩 들여씁니다. 한 줄이 길면 가로로 움직여 읽을 수 있습니다. 수정한 코드도 ‘들여쓰기 정리’로 정돈할 수 있으며, 저장해 둔 초안은 자동으로 바꾸지 않습니다.
