DAY 12 / 읽기 · 수정 · 실행

용돈 저금 계산기

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차기초 용어·들여쓰기 안내예제만 새 탭에서 열기
기초 정의핵심 정리코드 수정·실행복습문제

01. 핵심 개념

반복문, 매개변수·인수, 함수 호출, return

02. 실행 흐름

함수 호출 → 인수 받기 → 반복·계산 → return → 호출한 자리에서 결과 사용

기초부터 천천히 읽기

함수를 읽을 때는 입력·처리·결과를 나눕니다. 반복문은 그 처리 중 같은 일을 되풀이하는 부분입니다. 중괄호가 많아질수록 들여쓰기를 보고 어떤 코드가 반복 안에 있는지 확인하세요.

처음 보는 말의 정확한 뜻

함수 선언과 호출
function add(a, b) { ... }는 함수를 만드는 코드이고 add(2, 3)은 사용하는 호출입니다.
지역 변수
함수나 블록 안에 선언해 그 범위에서 사용하는 변수입니다. 함수 안 total을 바깥에서 바로 쓸 수 있는지 스코프를 확인합니다.
for의 세 부분
for(초기화; 조건; 증감)은 한 번 시작값을 정하고, 조건을 확인하고, 본문을 실행한 뒤 증감하는 구조입니다.
break와 continue
break는 반복을 끝내고, continue는 이번 본문의 남은 부분을 건너뛴 뒤 다음 차례로 진행합니다.
반환값
함수 호출의 결과로 받은 값입니다. console.log로 출력한 글자와 함수가 return한 값을 구분합니다.
화살표 함수
(a, b) => a + b처럼 함수를 쓰는 다른 문법입니다. 간단한 표현식 본문은 결과를 바로 반환하지만 {} 본문은 return을 확인합니다.

기호와 문법을 읽는 법

같은 기호도 문맥에 따라 역할이 달라집니다. 아래 설명은 이 페이지의 예제 기준입니다.

DAY12 기호와 예시
표기뜻짧은 예
()매개변수 자리 또는 호출 인수 자리입니다.add(2, 3)
{}함수나 반복문의 본문을 묶습니다.function add() { ... }
return결과를 돌려주고 현재 함수를 끝냅니다.return total
+=현재 값에 더해 다시 담습니다.total += 1000
=>화살표 함수 문법입니다.n => n + 1

짧은 코드 한 줄씩 읽기

function add(a, b) {
  const total = a + b;
  return total;
}

const result = add(2, 3);
console.log(result);
  1. 1줄의 a와 b는 받을 자리입니다. 함수 선언만으로 2줄의 계산이 바로 실행되는 것은 아닙니다.
  2. 6줄의 호출이 a에 2, b에 3을 넣고 함수를 실행합니다.
  3. 3줄이 계산값 5를 호출한 곳으로 돌려주므로 result에 5가 담깁니다.

예상 결과와 전제

콘솔에 5가 출력됩니다. return total을 지우면 함수가 끝났을 때 result는 undefined가 됩니다.

아래 실행 편집기에는 실행 가능한 전체 예제가 있습니다. 위 짧은 코드는 개념 설명용 발췌이며, 필요한 주변 코드와 전제를 함께 읽어 주세요.

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

반복문
같은 코드를 조건이나 횟수에 따라 되풀이하는 구조입니다. for, while 등이 있습니다.
while
조건이 참인 동안 본문을 반복합니다. 조건이 언젠가 거짓이 되도록 값이 바뀌는지 확인합니다.
함수
실행할 코드를 이름으로 묶은 것입니다. 만들어 두는 것과 호출하는 것은 다릅니다.
매개변수와 인수
매개변수는 함수가 값을 받을 자리이고, 인수는 호출할 때 실제로 넣는 값입니다.
return
계산 결과를 호출한 자리로 돌려주고 현재 함수 실행을 끝냅니다.
누적값
total처럼 반복마다 더해지는 값입니다. 처음 값을 어디에서 정하는지와 언제 갱신하는지가 중요합니다.

꼭 기억할 내용

  • 반복을 읽을 때는 시작값, 계속할 조건, 반복마다 바뀌는 값을 찾으세요.
  • 매달 저축액이 0이면 목표에 도달하지 못하므로 이 예제는 먼저 0 이하 입력을 처리합니다.
  • console.log로 보여 주는 것과 return으로 결과를 돌려주는 것은 다릅니다.
이 예제의 코드를 읽는 순서
  1. monthsToGoal(30000, 100000)이 monthly와 goal에 값을 넣습니다.
  2. total=0과 months=0으로 시작합니다.
  3. 목표보다 작으면 저축액과 달 수를 늘린 뒤 조건을 다시 검사합니다.
  4. 목표에 도달하면 반복을 끝내고 달 수를 return합니다.

자주 헷갈리는 부분

함수 안의 코드는 선언하는 순간 모두 실행될까요?

일반적으로 호출할 때 실행됩니다.

return 없이 출력만 하면 함수 밖에서 결과를 쓸 수 있을까요?

일반 함수가 return 없이 끝나면 호출 결과는 undefined입니다.

03. 직접 바꿔 보기

월 저축액 30000을 50000으로 바꾸고 몇 개월이 나올지 예상하세요.

먼저 결과를 예상하고 한두 줄만 바꿔 보세요. 화면 편집 내용은 이 브라우저에 자동 저장됩니다. 브라우저가 저장을 제한하면 저장되지 않을 수 있습니다.

코드는 안쪽 단계마다 두 칸씩 들여씁니다. 한 줄이 길면 가로로 움직여 읽을 수 있습니다. 수정한 코드도 ‘들여쓰기 정리’로 정돈할 수 있으며, 저장해 둔 초안은 자동으로 바꾸지 않습니다.
