1. 학습 사이트 폴더

맨 위에는 시작 화면과 각 메뉴의 HTML만 둡니다. 실제 동작과 자료는 역할별 폴더에 모았습니다. 

바이브코딩_복습/
├── index.html             ← 시작 화면: 이 파일부터 엽니다
├── curriculum.html        ← 전체 수업
├── lesson.html            ← 48개 수업이 사용하는 공통 학습 화면
├── glossary.html          ← 사용 분야별 용어 사전
├── projects.html          ← 실무 프로젝트 안내
├── setup.html             ← 설치·실행 준비
├── troubleshoot.html      ← 오류 해결
├── progress.html          ← 학습 기록과 백업
├── files.html             ← 지금 읽는 파일 안내
├── assets/                ← 학습 사이트를 구성하는 파일
│   ├── css/               ← 색상·크기·여백·배치
│   ├── js/                ← 검색·실습 실행·학습 기록 등 동작
│   ├── data/              ← 수업 본문과 과제 정답
│   └── vendor/            ← React·Babel·코드 정리 도구와 라이선스
├── projects/              ← 직접 실행하고 수정할 프로젝트 원본
├── downloads/             ← 프로젝트별 ZIP 압축 파일
└── archive/               ← 이전 자료 보관함
    └── previous-course/
        ├── DAY01/ …       ← 이전 날짜별 예제
        ├── 공통/          ← 이전 예제 전용 실행 파일
        └── 참고자료/      ← 이전 복습·발표 PDF

README.md는 자세한 폴더 안내, 읽어주세요.txt는 시작 방법입니다. 404.html은 예전 주소와 없는 페이지를 안내합니다. .git·.gitignore·.nojekyll은 버전 관리와 배포에 사용하는 보조 항목입니다.

2. 무엇을 바꾸려면 어떤 파일을 열까요?

바꾸고 싶은 것 열 파일 확인 방법
학습 사이트의 제목·메뉴·기본 구조 해당 메뉴의 .html 파일 저장한 뒤 그 페이지를 새로고침합니다.
사이트 글자 크기·여백·색상 assets/css/academy.css 컴퓨터·휴대폰 너비에서 함께 확인합니다.
용어 사전 분류·검색 동작 assets/js/glossary.js 분야 선택과 검색 결과를 확인합니다.
수업 본문·용어 정의 assets/data/curriculum.js 해당 수업과 용어 사전을 함께 확인합니다.
학습 사이트의 실행·메모·진도 기능 assets/js/academy.js 관련 레슨에서 실행·저장·다시 열기를 확인합니다.
과제 정답과 풀이 assets/data/solutions.js 수업의 정답 해설을 펼쳐 확인합니다.

assets/vendor는 외부 도구 원본입니다. 수업 문구나 카페 기능을 바꾸기 위해 직접 수정할 파일은 아닙니다.

3. 실습 프로젝트는 하나씩 꺼내 쓰세요

각 레슨 폴더의 .mjs 파일		 해당 폴더에서 README에 적힌 node 명령을 실행합니다.
