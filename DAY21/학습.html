오늘의 메뉴 고르기

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차예제만 새 탭에서 열기

01. 핵심 개념

import·export, 기본·이름 내보내기, 모듈, npm·package.json·Vite

02. 실행 흐름

모듈 가져오기 → 버튼 연결 → 메뉴 배열을 함수에 전달 → 선택 결과 표시

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

모듈
독립된 범위를 갖고 다른 파일과 필요한 값만 주고받는 코드 단위입니다.
export
다른 모듈이 사용할 값이나 함수를 이름으로 내보냅니다.
export default
모듈의 기본 내보내기를 정합니다. 가져오는 쪽은 중괄호 없이 지역 이름을 정할 수 있습니다.
import
다른 모듈의 값을 가져오는 문법입니다. 이름 내보내기와 기본 내보내기의 형태를 구분합니다.
npm / package.json
npm은 패키지와 프로젝트 명령을 관리하는 도구이고 package.json은 의존 패키지와 실행 명령 등의 정보를 담는 파일입니다.
Vite와 빌드
Vite는 개발 서버와 빌드 등을 돕는 도구입니다. 빌드는 소스를 배포할 형태로 처리하는 과정이며 개발 서버 실행과 구분합니다.

꼭 기억할 내용

  • 내보낸 이름과 가져오는 이름이 맞는지, 기본·이름 내보내기를 혼동하지 않았는지 확인하세요.
  • 이 예제는 더블클릭으로도 동작하도록 문자열에서 Blob 모듈을 만듭니다. 실제 수업처럼 별도 menu.js를 경로로 import한 구조와 다릅니다.
  • 일반적인 별도 파일 모듈 연습은 file:// 대신 수업의 로컬 서버 환경에서 확인합니다.
이 예제의 코드를 읽는 순서
  1. moduleSource 문자열 안의 export와 export default를 읽습니다.
  2. 그 내용을 가진 모듈을 준비해 import가 완료될 때까지 기다립니다.
  3. 받아 온 menus와 pickMenu를 클릭 핸들러에서 사용합니다.
  4. 선택한 메뉴를 result에 표시합니다.

자주 헷갈리는 부분

import의 중괄호는 장식일까요?

이름으로 내보낸 항목을 가져오는지와 관련됩니다. 이 예제의 동적 import 구조분해와 수업의 정적 import 문법을 구분해서 읽으세요.

npm install을 하면 개발 서버도 켜질까요?

패키지 준비와 npm run dev 같은 실행 명령은 별도 단계입니다.

로컬 실행에 맞게 일부를 재구성했습니다. 예제 안의 안내에서 실제 라이브러리·서버·파일 모듈과 다른 부분을 확인하세요.

03. 직접 바꿔 보기

menus에 "돈가스"를 추가하고 버튼을 여러 번 눌러 보세요. 문자열 안의 export 코드도 실제 모듈로 실행됩니다.

04. 복습문제

기본 내보내기와 이름 내보내기는 import 중괄호가 어떻게 다를까?

내가 답한 뒤 해설 보기

기본 내보내기는 import pickMenu from "./menu.js", 이름 내보내기는 import { menus } from "./menu.js"처럼 읽는다. 기본 import의 지역 이름은 바꿀 수 있다.
