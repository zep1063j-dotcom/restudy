오늘의 메뉴 고르기

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차기초 용어·들여쓰기 안내예제만 새 탭에서 열기
기초 정의핵심 정리코드 수정·실행복습문제

01. 핵심 개념

import·export, 기본·이름 내보내기, 모듈, npm·package.json·Vite

02. 실행 흐름

모듈 가져오기 → 버튼 연결 → 메뉴 배열을 함수에 전달 → 선택 결과 표시

기초부터 천천히 읽기

파일을 나누는 목적은 각각 맡는 일을 분명하게 하는 것입니다. 모든 파일을 열심히 외우기보다 내보내는 값과 가져오는 값을 따라가면 파일 사이의 실행 관계를 읽을 수 있습니다.

처음 보는 말의 정확한 뜻

정적 import
import { menus } from "./menu.js"처럼 모듈 맨 위에서 관계를 선언하는 문법입니다. 경로는 이 파일의 위치를 기준으로 읽습니다.
동적 import
import(url)은 모듈을 비동기로 가져와 모듈 객체로 이행되는 Promise를 돌려줍니다. 이 복습 예제는 이 방식을 사용합니다.
이름 내보내기와 기본 내보내기
한 모듈에서 여러 이름을 내보낼 수 있고 기본 내보내기는 하나입니다. 가져오는 문법과 이름을 각각 확인합니다.
dependencies와 devDependencies
프로젝트가 사용하는 패키지를 나누어 적는 항목입니다. 실제 배포 결과에 포함되는 코드는 빌드 방식에도 영향을 받습니다.
package-lock.json
패키지 해석 결과의 정확한 버전 정보를 기록해 설치 재현성을 돕는 파일입니다. package.json의 넓은 버전 조건과 역할이 다릅니다.
번들
여러 소스와 의존성을 실행·배포할 형태로 묶거나 처리한 결과입니다. 모듈 분리와 빌드 결과 파일 개수가 꼭 같지는 않습니다.

기호와 문법을 읽는 법

같은 기호도 문맥에 따라 역할이 달라집니다. 아래 설명은 이 페이지의 예제 기준입니다.

DAY21 기호와 예시
표기뜻짧은 예
export const이름을 붙여 값을 내보냅니다.export const menus = []
export default기본 내보내기를 지정합니다.export default pickMenu
import { name }이름 내보내기를 가져옵니다.import { menus } from "./menu.js"
import name기본 내보내기를 가져옵니다.import pick from "./menu.js"
./ / ../현재 또는 부모 폴더 기준 경로입니다."./menu.js"

짧은 코드 한 줄씩 읽기

// menu.js
export const menus = ["커피", "빵"];

// main.js
import { menus } from "./menu.js";
console.log(menus.length);
  1. 주석으로 구분한 두 파일의 내용입니다. 한 파일에 그대로 합쳐 실행하는 예제가 아닙니다.
  2. menu.js가 menus라는 이름을 내보내고 main.js가 같은 이름으로 가져옵니다.
  3. main.js는 받은 배열의 length를 읽습니다. 브라우저에서는 모듈을 지원하는 로컬 서버 환경 등을 사용합니다.

예상 결과와 전제

올바른 모듈 환경과 경로에서는 콘솔에 2가 출력됩니다. 현재 학습 페이지의 실행 예제는 파일 더블클릭을 위해 Blob 모듈로 재구성되어 있습니다.

아래 실행 편집기에는 실행 가능한 전체 예제가 있습니다. 위 짧은 코드는 개념 설명용 발췌이며, 필요한 주변 코드와 전제를 함께 읽어 주세요.

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

모듈
독립된 범위를 갖고 다른 파일과 필요한 값만 주고받는 코드 단위입니다.
export
다른 모듈이 사용할 값이나 함수를 이름으로 내보냅니다.
export default
모듈의 기본 내보내기를 정합니다. 가져오는 쪽은 중괄호 없이 지역 이름을 정할 수 있습니다.
import
다른 모듈의 값을 가져오는 문법입니다. 이름 내보내기와 기본 내보내기의 형태를 구분합니다.
npm / package.json
npm은 패키지와 프로젝트 명령을 관리하는 도구이고 package.json은 의존 패키지와 실행 명령 등의 정보를 담는 파일입니다.
Vite와 빌드
Vite는 개발 서버와 빌드 등을 돕는 도구입니다. 빌드는 소스를 배포할 형태로 처리하는 과정이며 개발 서버 실행과 구분합니다.

꼭 기억할 내용

  • 내보낸 이름과 가져오는 이름이 맞는지, 기본·이름 내보내기를 혼동하지 않았는지 확인하세요.
  • 이 예제는 더블클릭으로도 동작하도록 문자열에서 Blob 모듈을 만듭니다. 실제 수업처럼 별도 menu.js를 경로로 import한 구조와 다릅니다.
  • 일반적인 별도 파일 모듈 연습은 file:// 대신 수업의 로컬 서버 환경에서 확인합니다.
이 예제의 코드를 읽는 순서
  1. moduleSource 문자열 안의 export와 export default를 읽습니다.
  2. 그 내용을 가진 모듈을 준비해 import가 완료될 때까지 기다립니다.
  3. 받아 온 menus와 pickMenu를 클릭 핸들러에서 사용합니다.
  4. 선택한 메뉴를 result에 표시합니다.

자주 헷갈리는 부분

import의 중괄호는 장식일까요?

이름으로 내보낸 항목을 가져오는지와 관련됩니다. 이 예제의 동적 import 구조분해와 수업의 정적 import 문법을 구분해서 읽으세요.

npm install을 하면 개발 서버도 켜질까요?

패키지 준비와 npm run dev 같은 실행 명령은 별도 단계입니다.

로컬 실행에 맞게 일부를 재구성했습니다. 예제 안의 안내에서 실제 라이브러리·서버·파일 모듈과 다른 부분을 확인하세요.

03. 직접 바꿔 보기

menus에 "돈가스"를 추가하고 버튼을 여러 번 눌러 보세요. 문자열 안의 export 코드도 실제 모듈로 실행됩니다.

먼저 결과를 예상하고 한두 줄만 바꿔 보세요. 화면 편집 내용은 이 브라우저에 자동 저장됩니다. 브라우저가 저장을 제한하면 저장되지 않을 수 있습니다.

코드는 안쪽 단계마다 두 칸씩 들여씁니다. 한 줄이 길면 가로로 움직여 읽을 수 있습니다. 수정한 코드도 ‘들여쓰기 정리’로 정돈할 수 있으며, 저장해 둔 초안은 자동으로 바꾸지 않습니다.

04. 복습문제

기본 내보내기와 이름 내보내기는 import 중괄호가 어떻게 다를까?

내가 답한 뒤 해설 보기

기본 내보내기는 import pickMenu from "./menu.js", 이름 내보내기는 import { menus } from "./menu.js"처럼 읽는다. 기본 import의 지역 이름은 바꿀 수 있다.
