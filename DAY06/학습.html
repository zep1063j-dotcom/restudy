DAY 06 / 읽기 · 수정 · 실행

소개 영역 반응형과 다크 모드

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차기초 용어·들여쓰기 안내예제만 새 탭에서 열기
기초 정의핵심 정리코드 수정·실행복습문제

01. 핵심 개념

viewport, 상대 단위, 미디어 쿼리, 모바일 퍼스트

02. 실행 흐름

좁은 화면 기본 규칙 → 조건에 맞는 미디어 쿼리 추가 적용

기초부터 천천히 읽기

반응형은 다른 기기마다 내용을 따로 외워 만드는 일이 아니라, 어떤 폭과 환경에서 어느 규칙을 적용할지 정하는 일입니다. 기본 CSS와 조건에 맞는 추가 CSS를 차례로 읽습니다.

처음 보는 말의 정확한 뜻

고정 단위와 상대 단위
px는 CSS 픽셀 단위이고 rem·%·vw 등은 정해진 기준과의 관계로 크기를 표현합니다. 기준이 무엇인지 함께 확인합니다.
rem과 em
rem은 루트 요소의 글자 크기를 기준으로 합니다. em은 속성에 따라 기준이 달라지며, font-size에서는 부모의 글자 크기를 기준으로 읽습니다.
%와 vw / vh
%는 속성별 기준이 달라집니다. vw와 vh는 뷰포트 너비·높이의 1%를 나타내는 단위입니다.
중단점
레이아웃 규칙을 바꾸는 기준 폭입니다. 기기 이름을 외우기보다 해당 값의 전후에서 확인합니다.
1fr
Grid의 남는 공간을 비율로 나누는 단위입니다. 1fr 1fr은 두 트랙에 같은 비율로 공간을 나눕니다.
규칙의 적용 순서
조건에 맞는 미디어 쿼리가 여러 개면 모두 후보가 됩니다. 구체성과 선언 순서 등 CSS의 우선 조건을 함께 판단합니다.

기호와 문법을 읽는 법

같은 기호도 문맥에 따라 역할이 달라집니다. 아래 설명은 이 페이지의 예제 기준입니다.

DAY06 기호와 예시
표기뜻짧은 예
@media조건부 CSS를 시작합니다.@media (...) { ... }
min-width이 폭 이상일 때입니다.min-width: 600px
1fr 1fr두 개의 같은 비율 열을 뜻합니다.grid-template-columns: 1fr 1fr
and조건을 동시에 만족해야 합니다.(min-width: 600px) and (...)
rem루트 글자 크기에 비례합니다.padding: 1rem

짧은 코드 한 줄씩 읽기

.cards {
  grid-template-columns: 1fr;
}

@media (min-width: 600px) {
  .cards {
    grid-template-columns: 1fr 1fr;
  }
}
  1. 기본 규칙은 한 열입니다. 이 조각은 .cards에 display:grid가 이미 있다는 전제입니다.
  2. 폭이 600px 이상이면 같은 .cards의 열 설정을 두 열로 바꿉니다.
  3. 600이라는 숫자를 바꾸면 문구나 데이터가 아니라 배치가 바뀌는 시점이 달라집니다.

예상 결과와 전제

해당 요소가 Grid일 때 599px 화면에서는 한 열, 600px 이상에서는 두 열입니다. 이 학습 페이지에서는 미리보기 iframe 폭을 기준으로 확인합니다.

아래 실행 편집기에는 실행 가능한 전체 예제가 있습니다. 위 짧은 코드는 개념 설명용 발췌이며, 필요한 주변 코드와 전제를 함께 읽어 주세요.

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

반응형 웹
같은 문서가 화면 폭이나 환경에 따라 다른 배치로 보이게 하는 방식입니다.
viewport
브라우저가 웹페이지를 배치할 때 기준으로 사용하는 화면 영역입니다. 모바일의 viewport 메타 설정도 확인합니다.
미디어 쿼리
@media 조건 안에 특정 화면 조건에서만 쓸 CSS를 적는 문법입니다.
min-width / max-width
min-width는 기준 이상, max-width는 기준 이하일 때를 뜻합니다.
모바일 퍼스트
좁은 화면의 기본 모양을 먼저 정한 뒤 넓은 화면에서 추가할 규칙을 쌓는 방식입니다.
prefers-color-scheme
사용자의 밝은 모드·어두운 모드 선호에 맞춰 스타일을 적용하는 조건입니다.

꼭 기억할 내용

  • 이 예제의 조건은 바깥 브라우저 전체가 아니라 실행 결과 iframe의 폭에 적용됩니다.
  • 연습 예제는 600px를 경계로 사용합니다. 수업의 768px 등과 구분하고, 조건 자체를 읽는 연습을 하세요.
  • 다크 모드에서는 배경만 바꾸지 말고 글자와 링크가 보이는지도 확인하세요.
이 예제의 코드를 읽는 순서
  1. 기본 .cards는 1fr이므로 한 열로 놓입니다.
  2. 미리보기를 360px로 만들면 min-width:600px 조건에 맞지 않습니다.
  3. 800px로 넓히면 1fr 1fr 규칙이 적용되어 두 열로 바뀝니다.

자주 헷갈리는 부분

min-width 600px는 600px보다 작은 화면이라는 뜻일까요?

아닙니다. 600px 이상입니다.

반응형이란 모바일용 HTML을 따로 만드는 것일까요?

이 예제에서는 같은 HTML에 조건부 CSS를 적용합니다.

03. 직접 바꿔 보기

아래 화면 폭을 바꿔 1열과 2열을 비교하세요. 경계값 600px를 700px로 바꾸세요.

먼저 결과를 예상하고 한두 줄만 바꿔 보세요. 화면 편집 내용은 이 브라우저에 자동 저장됩니다. 브라우저가 저장을 제한하면 저장되지 않을 수 있습니다.

코드는 안쪽 단계마다 두 칸씩 들여씁니다. 한 줄이 길면 가로로 움직여 읽을 수 있습니다. 수정한 코드도 ‘들여쓰기 정리’로 정돈할 수 있으며, 저장해 둔 초안은 자동으로 바꾸지 않습니다.
