DAY 06 / 읽기 · 수정 · 실행

소개 영역 반응형과 다크 모드

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차예제만 새 탭에서 열기

01. 핵심 개념

viewport, 상대 단위, 미디어 쿼리, 모바일 퍼스트

02. 실행 흐름

좁은 화면 기본 규칙 → 조건에 맞는 미디어 쿼리 추가 적용

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

반응형 웹
같은 문서가 화면 폭이나 환경에 따라 다른 배치로 보이게 하는 방식입니다.
viewport
브라우저가 웹페이지를 배치할 때 기준으로 사용하는 화면 영역입니다. 모바일의 viewport 메타 설정도 확인합니다.
미디어 쿼리
@media 조건 안에 특정 화면 조건에서만 쓸 CSS를 적는 문법입니다.
min-width / max-width
min-width는 기준 이상, max-width는 기준 이하일 때를 뜻합니다.
모바일 퍼스트
좁은 화면의 기본 모양을 먼저 정한 뒤 넓은 화면에서 추가할 규칙을 쌓는 방식입니다.
prefers-color-scheme
사용자의 밝은 모드·어두운 모드 선호에 맞춰 스타일을 적용하는 조건입니다.

꼭 기억할 내용

  • 이 예제의 조건은 바깥 브라우저 전체가 아니라 실행 결과 iframe의 폭에 적용됩니다.
  • 연습 예제는 600px를 경계로 사용합니다. 수업의 768px 등과 구분하고, 조건 자체를 읽는 연습을 하세요.
  • 다크 모드에서는 배경만 바꾸지 말고 글자와 링크가 보이는지도 확인하세요.
이 예제의 코드를 읽는 순서
  1. 기본 .cards는 1fr이므로 한 열로 놓입니다.
  2. 미리보기를 360px로 만들면 min-width:600px 조건에 맞지 않습니다.
  3. 800px로 넓히면 1fr 1fr 규칙이 적용되어 두 열로 바뀝니다.

자주 헷갈리는 부분

min-width 600px는 600px보다 작은 화면이라는 뜻일까요?

아닙니다. 600px 이상입니다.

반응형이란 모바일용 HTML을 따로 만드는 것일까요?

이 예제에서는 같은 HTML에 조건부 CSS를 적용합니다.
