DAY 16 / 읽기 · 수정 · 실행

물 마시기 기록 버튼 만들기

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차기초 용어·들여쓰기 안내예제만 새 탭에서 열기
기초 정의핵심 정리코드 수정·실행복습문제

01. 핵심 개념

이벤트와 콜백, input·change·submit, preventDefault

02. 실행 흐름

클릭 → 연결 함수 호출 → 잔 수 변경 → 목표 판정 → 화면 반영

기초부터 천천히 읽기

이벤트를 등록하는 코드는 “나중에 이 일이 생기면 이 함수를 실행해 달라”는 연결입니다. 등록하는 순간과 실제 클릭 순간을 구분하면 함수의 괄호 실수도 이해할 수 있습니다.

처음 보는 말의 정확한 뜻

함수 값과 호출 결과
handleClick은 함수 자체이고 handleClick()은 실행한 뒤 얻는 반환값입니다. 이벤트 등록에는 실행할 함수 값이 필요합니다.
이벤트 대상
event.target은 사건이 처음 일어난 요소, event.currentTarget은 현재 핸들러를 등록한 요소입니다. 내부에 다른 요소가 있으면 다를 수 있습니다.
기본 동작
링크 이동이나 폼 제출처럼 브라우저가 기본으로 수행하는 일입니다. preventDefault는 취소 가능한 기본 동작을 막습니다.
이벤트 전파
안쪽 요소에서 일어난 이벤트가 바깥 요소의 처리에도 이어질 수 있는 구조입니다. 기본 동작 취소와 전파 중지는 같은 뜻이 아닙니다.
입력값 읽는 시점
클릭할 때 .value를 읽으면 그때의 값이고, 처음 실행할 때 읽어 둔 변수는 이후 입력을 자동으로 따라가지 않습니다.
데이터와 표시
cups 변수는 숫자 데이터이고 textContent는 표시할 내용입니다. 같은 값이 되도록 반영하는 줄까지 따라가야 합니다.

기호와 문법을 읽는 법

같은 기호도 문맥에 따라 역할이 달라집니다. 아래 설명은 이 페이지의 예제 기준입니다.

DAY16 기호와 예시
표기뜻짧은 예
"click"등록할 이벤트 이름입니다.addEventListener("click", fn)
() => { }나중에 실행할 함수입니다.() => { cups += 1; }
+=현재 값에 더해 다시 넣습니다.cups += 1
event.target이벤트가 일어난 요소를 읽습니다.event.target.value
.textContent화면에 보이는 글자를 정합니다.result.textContent = "1잔"

짧은 코드 한 줄씩 읽기

let cups = 0;

button.addEventListener("click", () => {
  cups += 1;
  result.textContent = `${cups}잔`;
});
  1. button과 result가 요소를 가리키고 있다는 전제의 코드입니다.
  2. 이벤트를 연결할 때 4~5줄은 아직 실행하지 않습니다.
  3. 클릭하면 cups를 1 증가시킨 후 새로운 값으로 글자를 만듭니다.

예상 결과와 전제

처음 클릭하면 1잔, 두 번째 클릭하면 2잔입니다. 4줄의 1을 2로 바꾸면 클릭마다 2잔씩 증가합니다.

아래 실행 편집기에는 실행 가능한 전체 예제가 있습니다. 위 짧은 코드는 개념 설명용 발췌이며, 필요한 주변 코드와 전제를 함께 읽어 주세요.

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

이벤트
클릭, 입력, 제출처럼 브라우저에서 일어나는 일입니다.
이벤트 핸들러
이벤트가 일어났을 때 실행하도록 연결한 함수입니다.
addEventListener
요소에 이벤트 종류와 실행할 함수를 연결하는 메서드입니다.
이벤트 객체
무슨 일이 일어났는지 담긴 값입니다. target은 발생 요소, key는 키보드 이벤트의 키 이름 등을 나타냅니다.
input / change / submit
input은 값 편집 때, change는 요소 종류에 따른 값 확정 때, submit은 폼 제출 때 사용합니다.
화면 반영
변수만 바꾸는 것과 화면 글자를 바꾸는 것은 별개입니다. 이 예제는 textContent와 style을 직접 갱신합니다.

꼭 기억할 내용

  • addEventListener의 이벤트 이름은 "click"처럼 적고, 실행할 함수는 함수 값으로 넘깁니다.
  • 이 예제의 cups는 데이터이고 result.textContent는 화면입니다. 둘이 어떻게 연결되는지 읽으세요.
  • 목표 도달 조건은 cups >= goal입니다. 정확히 목표와 같을 때도 성공입니다.
이 예제의 코드를 읽는 순서
  1. cups는 0으로 시작하고 버튼에 콜백을 연결합니다.
  2. 클릭하면 cups를 1 증가시킵니다.
  3. 새 잔 수를 화면에 적습니다.
  4. 목표 이상이면 글자색을 초록색으로 정합니다.

자주 헷갈리는 부분

handleClick과 handleClick()은 같을까요?

전자는 나중에 호출할 함수를 전달하고, 후자는 지금 호출한 결과를 전달합니다.

cups 값을 바꾸면 화면이 자동으로 바뀔까요?

일반 DOM 예제에서는 화면을 갱신하는 줄도 실행해야 합니다. React의 state와 구분하세요.

03. 직접 바꿔 보기

한 번 클릭할 때 2잔 증가하도록 바꾸고 목표에 몇 번 만에 도달하는지 확인하세요.

먼저 결과를 예상하고 한두 줄만 바꿔 보세요. 화면 편집 내용은 이 브라우저에 자동 저장됩니다. 브라우저가 저장을 제한하면 저장되지 않을 수 있습니다.

코드는 안쪽 단계마다 두 칸씩 들여씁니다. 한 줄이 길면 가로로 움직여 읽을 수 있습니다. 수정한 코드도 ‘들여쓰기 정리’로 정돈할 수 있으며, 저장해 둔 초안은 자동으로 바꾸지 않습니다.

04. 복습문제

이벤트에 handleClick과 handleClick()을 넘기는 차이는?

내가 답한 뒤 해설 보기

handleClick은 나중에 실행할 함수를 전달한다. handleClick()은 지금 실행하고 그 반환값을 전달한다.
