DAY 27 / 읽기 · 수정 · 실행

오즈 카페 — 프로젝트 시작

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차예제만 새 탭에서 열기

01. 핵심 개념

Node.js·npm·nvm, scripts, 개발 서버, 프로젝트 파일 구조

02. 실행 흐름

프로젝트 준비 → 의존 패키지 설치 → 개발 서버 → index.html → main.jsx → App

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

Node.js
브라우저 밖에서 JavaScript를 실행하는 환경입니다. 개발 도구를 실행할 때도 사용합니다.
npm / nvm
npm은 패키지와 프로젝트 명령을 관리하고, nvm은 Node.js 버전을 설치·전환하는 도구입니다.
개발 서버
작성한 소스를 브라우저에서 확인하도록 제공하는 개발용 서버입니다. 수업에서는 Vite를 사용합니다.
index.html / root
브라우저가 읽는 문서와 React가 화면을 넣을 대상 요소입니다. 이 예제는 id="root"를 사용합니다.
컴포넌트
화면의 한 부분을 설명하는 React 함수입니다. 보통 대문자로 시작하는 이름을 쓰고 JSX를 반환합니다.
JSX
JavaScript 안에서 화면 구조를 HTML과 비슷하게 적는 문법입니다. 브라우저 실행 전에 변환 과정이 필요합니다.

꼭 기억할 내용

  • 이 페이지는 설치 없이 읽도록 React와 JSX 변환 도구를 폴더에 포함했습니다. Vite 프로젝트 설치·실행 과정을 그대로 재현하지는 않습니다.
  • 컴포넌트 함수가 반환하는 내용과, 그 컴포넌트를 실제 root에 렌더하는 줄을 구분하세요.
  • 외부 패키지를 가져온 프로젝트에서는 해당 폴더의 package.json과 명령을 먼저 확인합니다.
이 예제의 코드를 읽는 순서
  1. root 요소가 처음에는 비어 있는 것을 확인합니다.
  2. 로컬 React와 변환 도구를 불러옵니다.
  3. App이 제목과 소개 문장을 포함한 JSX를 반환합니다.
  4. createRoot(...).render(<App />)가 App의 내용을 root에 그립니다.

자주 헷갈리는 부분

JSX 파일은 HTML 파일처럼 아무 브라우저에서 바로 해석될까요?

JSX는 변환이 필요합니다. 이 복습 예제와 수업의 Vite는 변환 방법이 다릅니다.

npm run dev와 배포는 같은 뜻일까요?

개발 중 화면 확인과 실제 서비스 배포는 다른 과정입니다.

실제 React와 JSX를 사용합니다. 로컬에 포함한 React와 변환 도구로 실행하며, 강의의 Vite 설치 절차를 재현한 것은 아닙니다. 화면 편집기에서 JSX도 바꿀 수 있습니다.

04. 복습문제

npm install과 npm run dev는 각각 무슨 일을 할까?

내가 답한 뒤 해설 보기

install은 의존 패키지를 준비하고, run dev는 package.json의 dev 스크립트를 실행한다. 수업 ZIP에서는 Vite 개발 서버를 시작한다.
