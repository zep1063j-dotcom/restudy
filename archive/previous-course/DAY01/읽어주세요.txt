DAY01 웹의 동작 구조와 HTML 기초

1. 학습.html을 더블클릭합니다.
2. 핵심 개념과 실행 흐름을 읽습니다.
3. 페이지 안의 코드 편집기에서 수정하고 실행을 누릅니다.
4. 예제.html은 독립 실행 가능한 시작 코드입니다. 파일을 직접 수정한 뒤 브라우저에서 다시 열어도 됩니다.
5. 학습 페이지의 편집 내용과 예제.html 파일은 서로 자동으로 덮어쓰지 않습니다.
