이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차기초 용어·들여쓰기 안내예제만 새 탭에서 열기
기초 정의핵심 정리코드 수정·실행복습문제

01. 핵심 개념

const·let, 자료형, typeof, 오류 종류

02. 실행 흐름

값 선언 → 계산·문자열 조합 → Console 출력

기초부터 천천히 읽기

JavaScript는 값을 읽고 계산한 뒤 다음 작업에 전달합니다. 먼저 값의 종류, 이름을 붙이는 방법, 값을 출력하는 방법을 익히면 이후 조건문과 함수도 읽기 쉬워집니다.

처음 보는 말의 정확한 뜻

선언과 대입
const price = 4000은 이름을 선언하면서 처음 값을 넣는 코드입니다. price = 5000은 이미 있는 이름에 다시 대입하려는 코드입니다.
문자열
글자로 다루는 값입니다. "4000"도 따옴표로 감쌌으므로 숫자 계산값이 아닌 문자열입니다.
숫자와 불리언
4000은 숫자, true와 false는 불리언 값입니다. 불리언은 조건 판단 결과를 표현할 때 자주 만납니다.
undefined와 null
undefined는 값이 아직 없거나 제공되지 않은 경우에 자주 나타납니다. null은 의도적으로 비어 있음을 표시할 때 사용합니다. 구체적 의미는 코드의 약속을 확인합니다.
NaN
숫자 변환이나 계산이 숫자로 성립하지 않을 때 만나는 특수한 숫자 값입니다. Number("커피")의 결과가 예입니다.
템플릿 문자열
백틱으로 감싸고 ${표현식}으로 값을 끼워 넣는 문자열입니다. 일반 따옴표의 문자열과 구분합니다.
표현식
계산되어 하나의 값이 되는 코드입니다. 4000 + 500, price, getPrice() 등이 표현식으로 쓰일 수 있습니다.

짧은 코드 한 줄씩 읽기

const raw = "4000";
const price = Number(raw);
const total = price + 500;
console.log(`${total}원`);
  1. 1줄 raw는 문자열입니다. const는 이후 raw를 다른 값으로 재대입하지 않겠다는 선언입니다.
  2. 2줄 Number(raw)는 문자열을 숫자로 바꾸고 price라는 이름으로 읽게 합니다.
  3. 3줄은 숫자끼리 더하고 4줄은 그 결과를 문구에 넣어 콘솔에 출력합니다.

예상 결과와 전제

콘솔에 4500원이 표시됩니다. 2줄의 Number 변환 없이 raw + 500을 계산하면 문자열 "4000500"이 됩니다.

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

변수
값을 이름으로 가리키는 방법입니다. 선언한 이름을 나중에 읽거나 계산에 사용할 수 있습니다.
const / let
const는 같은 이름에 다른 값을 다시 대입할 수 없고, let은 재대입할 수 있습니다. const 객체의 내부 속성까지 자동으로 고정되는 것은 아닙니다.
자료형
문자열, 숫자, 불리언 등 값의 종류입니다. 같은 4000이라도 "4000"과 4000은 자료형이 다릅니다.
typeof
값의 자료형 이름을 문자열로 확인하는 연산자입니다. 오래된 예외로 typeof null은 "object"입니다.
Number()
값을 숫자로 변환하는 함수입니다. 변환할 수 없는 문자열은 NaN이 될 수 있어 입력 검사와 함께 읽습니다.
console.log
값을 개발자 도구 콘솔에 출력합니다. 이 학습 페이지는 그 출력을 아래 콘솔 영역에도 보여 줍니다.

꼭 기억할 내용

  • 덧셈의 한쪽이 문자열이면 문자열 연결이 될 수 있습니다. 가격 계산이 이상하면 먼저 자료형을 확인하세요.
  • SyntaxError는 문법, ReferenceError는 찾지 못한 이름, TypeError는 맞지 않는 종류의 값이나 동작과 관련된 오류입니다.
  • 오류를 볼 때는 이름뿐 아니라 내용·파일·위치를 함께 읽으세요.
이 예제의 코드를 읽는 순서
  1. inputPrice는 따옴표로 감싸서 문자열입니다.
  2. wrong은 문자열에 500을 이어 붙입니다.
  3. correct는 Number로 변환한 뒤 500을 더합니다.
  4. 두 결과를 콘솔과 화면에 각각 출력합니다.

자주 헷갈리는 부분

const를 쓰면 값 내부를 전혀 바꿀 수 없을까요?

재대입을 막는다는 뜻입니다. 배열·객체의 내부 변경과는 구분해야 합니다.

input type="number"면 .value도 숫자일까요?

일반적인 .value는 문자열입니다. 숫자 변환 또는 valueAsNumber 등을 의도에 맞게 사용합니다.
