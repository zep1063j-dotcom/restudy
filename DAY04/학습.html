DAY 04 / 읽기 · 수정 · 실행

선택자로 스타일 입히기

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차기초 용어·들여쓰기 안내예제만 새 탭에서 열기
기초 정의핵심 정리코드 수정·실행복습문제

01. 핵심 개념

외부 CSS 연결, .class·#id, 후손·자식 선택자, 우선순위

02. 실행 흐름

HTML의 대상 → 일치하는 CSS 규칙 → 겹치는 규칙을 판단 → 최종 모양

기초부터 천천히 읽기

CSS를 읽을 때는 “누구에게 적용하는가”와 “무엇을 바꾸는가”를 나눕니다. 앞의 선택자가 대상을 정하고 중괄호 안의 선언이 색·크기·여백 같은 모양을 정합니다.

처음 보는 말의 정확한 뜻

선언
CSS에서 color: teal;처럼 속성과 값으로 적은 한 가지 설정입니다. 여러 선언을 한 규칙에 넣을 수 있습니다.
선택자와 속성의 차이
.menu는 대상을 고르는 선택자이고 color는 바꿀 속성입니다. 이름이 비슷해 보여도 역할이 다릅니다.
외부 스타일시트
별도 .css 파일을 link로 연결한 것입니다. 연결 경로가 틀리면 파일 안의 규칙을 적용할 수 없습니다.
후손과 자식 선택자
nav a는 nav 안쪽의 모든 단계에 있는 a를, nav > a는 바로 아래 자식인 a를 고릅니다.
상속
글자색처럼 일부 CSS 속성은 부모의 값이 자식에게 이어질 수 있습니다. 모든 속성이 상속되는 것은 아닙니다.
가상 클래스와 가상 요소
:hover는 상태에 맞는 요소를 고르고, ::before는 내용 앞에 생성되는 가상 요소를 다룹니다. 실제 HTML 태그가 새로 생기는 것과 구분합니다.

기호와 문법을 읽는 법

같은 기호도 문맥에 따라 역할이 달라집니다. 아래 설명은 이 페이지의 예제 기준입니다.

DAY04 기호와 예시
표기뜻짧은 예
.class 선택자를 시작합니다..menu
#id 선택자를 시작합니다.#special
{ }이 대상에 적용할 선언을 묶습니다..menu { ... }
:속성과 값을 구분합니다.color: teal
;선언의 끝을 구분합니다.color: teal;

짧은 코드 한 줄씩 읽기

.order-button {
  background: teal;
  color: white;
}
  1. 1줄은 class에 order-button이 있는 요소를 고릅니다.
  2. 2줄은 배경을, 3줄은 글자색을 설정합니다. 같은 중괄호 안이라 같은 대상에 적용됩니다.
  3. HTML의 class 이름을 다른 것으로 바꾸면 이 선택자도 여전히 일치하는지 확인해야 합니다.

예상 결과와 전제

이 규칙이 적용되는 버튼의 배경은 청록색, 글자는 흰색이 됩니다. 더 우선하는 다른 규칙이 있다면 최종 값은 달라질 수 있습니다.

아래 실행 편집기에는 실행 가능한 전체 예제가 있습니다. 위 짧은 코드는 개념 설명용 발췌이며, 필요한 주변 코드와 전제를 함께 읽어 주세요.

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

CSS 규칙
선택자 { 속성: 값; }의 형태입니다. 선택자로 대상을 고르고 중괄호 안에서 모양을 정합니다.
class 선택자
점으로 시작합니다. .order-button은 class="order-button"인 요소들을 고릅니다.
id 선택자
#으로 시작합니다. #special은 id="special"인 요소를 고릅니다. 같은 문서에서 id는 고유하게 사용합니다.
캐스케이딩과 우선순위
여러 규칙이 같은 속성을 정할 때 어떤 값이 적용될지 결정하는 과정입니다. 중요도·출처·레이어·선택자 구체성·순서 등이 관계됩니다.
:hover
마우스를 올린 상태의 요소를 고르는 가상 클래스입니다. 모바일에서 마우스와 똑같이 동작한다고 가정하지 않습니다.

꼭 기억할 내용

  • 이 예제처럼 같은 조건의 일반 규칙끼리는 id 선택자가 class 선택자보다 구체적입니다. 따라서 특별 주문의 배경은 #special 규칙을 먼저 확인합니다.
  • 선택자는 정확히 일치해야 합니다. HTML의 class 이름을 바꾸면 CSS와 JavaScript에서 같은 이름을 쓰는지도 살펴보세요.
  • CSS가 예상과 다르면 개발자 도구의 적용 스타일과 취소선을 확인하세요.
이 예제의 코드를 읽는 순서
  1. HTML에서 두 버튼에 붙은 class와 id를 확인합니다.
  2. .order-button이 두 버튼 모두에 일치하는지 봅니다.
  3. #special이 두 번째 버튼의 배경색을 덮어쓰는 이유를 읽습니다.

자주 헷갈리는 부분

가장 아래에 쓴 CSS가 항상 이길까요?

아닙니다. 다른 우선 조건이 같은 경우에 뒤의 규칙이 적용됩니다.

색이 안 바뀌면 !important를 붙이면 될까요?

먼저 연결 파일, 선택자 일치와 기존 규칙을 확인하세요. 덮어쓰기를 쌓으면 원인 파악이 어려워질 수 있습니다.

03. 직접 바꿔 보기

첫 버튼의 배경색을 바꾸세요. 특별 주문 버튼까지 같은 색이 되는지 예상해 보세요.

먼저 결과를 예상하고 한두 줄만 바꿔 보세요. 화면 편집 내용은 이 브라우저에 자동 저장됩니다. 브라우저가 저장을 제한하면 저장되지 않을 수 있습니다.

코드는 안쪽 단계마다 두 칸씩 들여씁니다. 한 줄이 길면 가로로 움직여 읽을 수 있습니다. 수정한 코드도 ‘들여쓰기 정리’로 정돈할 수 있으며, 저장해 둔 초안은 자동으로 바꾸지 않습니다.
