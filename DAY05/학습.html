DAY 05 / 읽기 · 수정 · 실행

소개 영역과 NEW 배지 만들기

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차예제만 새 탭에서 열기

01. 핵심 개념

content·padding·border·margin, Flexbox·Grid, position

02. 실행 흐름

요소 크기 계산 → 부모 배치 규칙 적용 → 자식 배치. 배지의 위치는 기준 조상에 좌우된다.

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

박스 모델
요소의 크기를 내용(content), 안쪽 여백(padding), 테두리(border), 바깥 여백(margin)으로 읽는 방법입니다.
box-sizing
width와 height를 어떤 범위로 계산할지 정합니다. border-box는 지정한 너비에 padding과 border를 포함합니다.
Flexbox / Grid
자식 요소들을 배치하는 CSS 도구입니다. 한 축의 배치는 Flexbox, 행과 열을 함께 맞추는 배치는 Grid를 먼저 검토할 수 있습니다.
gap
Flexbox나 Grid에서 항목 사이 간격을 정합니다. 카드 자체의 안쪽 여백과는 다릅니다.
relative / absolute
relative는 원래 자리 기준 이동과 배치 기준점 설정에 쓰입니다. absolute는 일반 흐름에서 빠져 위치 기준 조상을 따라 배치됩니다.

꼭 기억할 내용

  • padding을 늘리면 내용과 테두리 사이가 벌어지고, gap을 늘리면 카드 사이가 벌어집니다.
  • 이 예제의 .product는 relative이므로 그 안의 absolute 배지가 각 카드에 붙습니다.
  • absolute 요소가 예상하지 못한 곳에 있으면 기준점이 되는 조상을 먼저 찾으세요.
이 예제의 코드를 읽는 순서
  1. .cards의 display와 gap이 자식 카드 배치를 정합니다.
  2. .product의 width·padding·border가 카드 크기와 안쪽 공간을 정합니다.
  3. .badge의 top·right가 카드의 오른쪽 위 위치를 정합니다.

자주 헷갈리는 부분

width가 같으면 보이는 너비도 항상 같을까요?

box-sizing과 padding·border가 다르면 달라질 수 있습니다.

absolute는 무조건 화면을 기준으로 배치될까요?

아닙니다. 위치 기준이 되는 조상이 있는지 확인해야 합니다. 이 예제는 .product입니다.

04. 복습문제

width 200, padding 좌우 20씩, border 좌우 5씩이면 기본 박스의 너비는?

내가 답한 뒤 해설 보기

기본 content-box에서는 200+40+10=250px. border-box라면 테두리까지 200px이다. 바깥 margin은 별도다.
