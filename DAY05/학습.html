DAY 05 / 읽기 · 수정 · 실행

소개 영역과 NEW 배지 만들기

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차기초 용어·들여쓰기 안내예제만 새 탭에서 열기
기초 정의핵심 정리코드 수정·실행복습문제

01. 핵심 개념

content·padding·border·margin, Flexbox·Grid, position

02. 실행 흐름

요소 크기 계산 → 부모 배치 규칙 적용 → 자식 배치. 배지의 위치는 기준 조상에 좌우된다.

기초부터 천천히 읽기

화면의 요소를 상자라고 생각하고 안쪽 공간, 테두리, 바깥 간격을 분리해 읽습니다. 배치가 어긋났을 때는 자식 요소뿐 아니라 그 요소를 담는 부모의 배치 규칙도 확인합니다.

처음 보는 말의 정확한 뜻

content와 padding
content는 글자나 이미지가 놓이는 내용 영역이고 padding은 내용과 테두리 사이의 안쪽 공간입니다.
border와 margin
border는 테두리이고 margin은 상자 바깥쪽 여백입니다. width에 margin까지 포함된다고 생각하지 않습니다.
일반 흐름
브라우저가 요소를 기본 배치 규칙에 따라 놓는 흐름입니다. position:absolute 같은 설정은 이 흐름에서 요소를 빼서 배치합니다.
주축과 교차축
Flexbox의 flex-direction이 정하는 축을 주축, 그와 직각인 축을 교차축이라고 부릅니다. row일 때와 column일 때를 구분합니다.
flex-wrap
Flexbox 항목을 한 줄에 유지할지 여러 줄로 넘길지 정합니다. 이 예제는 wrap으로 폭이 좁으면 다음 줄을 허용합니다.
좌표 기준
top·right 같은 값은 기준점과 함께 읽어야 합니다. absolute는 위치 기준이 되는 조상이 어디인지 찾는 것이 먼저입니다.

기호와 문법을 읽는 법

같은 기호도 문맥에 따라 역할이 달라집니다. 아래 설명은 이 페이지의 예제 기준입니다.

DAY05 기호와 예시
표기뜻짧은 예
pxCSS 픽셀 단위입니다.padding: 20px
width설정한 계산 방식에 따른 너비입니다.width: 200px
display레이아웃에 참여하는 방식을 정합니다.display: flex
gap항목 사이 간격입니다.gap: 16px
position위치 지정 방식을 정합니다.position: relative

짧은 코드 한 줄씩 읽기

.product {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 2px solid teal;
}
  1. border-box이므로 width 200px 안에 좌우 padding과 border가 포함됩니다.
  2. 좌우 padding 합계는 40px, 테두리는 4px이므로 내용 영역의 너비는 156px입니다.
  3. margin이 있다면 이 200px 바깥에 추가로 고려합니다.

예상 결과와 전제

테두리를 포함한 카드 너비는 200px입니다. content-box로 바꾸면 같은 선언에서 테두리까지의 너비는 244px이 됩니다.

아래 실행 편집기에는 실행 가능한 전체 예제가 있습니다. 위 짧은 코드는 개념 설명용 발췌이며, 필요한 주변 코드와 전제를 함께 읽어 주세요.

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

박스 모델
요소의 크기를 내용(content), 안쪽 여백(padding), 테두리(border), 바깥 여백(margin)으로 읽는 방법입니다.
box-sizing
width와 height를 어떤 범위로 계산할지 정합니다. border-box는 지정한 너비에 padding과 border를 포함합니다.
Flexbox / Grid
자식 요소들을 배치하는 CSS 도구입니다. 한 축의 배치는 Flexbox, 행과 열을 함께 맞추는 배치는 Grid를 먼저 검토할 수 있습니다.
gap
Flexbox나 Grid에서 항목 사이 간격을 정합니다. 카드 자체의 안쪽 여백과는 다릅니다.
relative / absolute
relative는 원래 자리 기준 이동과 배치 기준점 설정에 쓰입니다. absolute는 일반 흐름에서 빠져 위치 기준 조상을 따라 배치됩니다.

꼭 기억할 내용

  • padding을 늘리면 내용과 테두리 사이가 벌어지고, gap을 늘리면 카드 사이가 벌어집니다.
  • 이 예제의 .product는 relative이므로 그 안의 absolute 배지가 각 카드에 붙습니다.
  • absolute 요소가 예상하지 못한 곳에 있으면 기준점이 되는 조상을 먼저 찾으세요.
이 예제의 코드를 읽는 순서
  1. .cards의 display와 gap이 자식 카드 배치를 정합니다.
  2. .product의 width·padding·border가 카드 크기와 안쪽 공간을 정합니다.
  3. .badge의 top·right가 카드의 오른쪽 위 위치를 정합니다.

자주 헷갈리는 부분

width가 같으면 보이는 너비도 항상 같을까요?

box-sizing과 padding·border가 다르면 달라질 수 있습니다.

absolute는 무조건 화면을 기준으로 배치될까요?

아닙니다. 위치 기준이 되는 조상이 있는지 확인해야 합니다. 이 예제는 .product입니다.

03. 직접 바꿔 보기

gap 16px를 32px로, padding 24px를 12px로 바꾸고 차이를 비교하세요.

먼저 결과를 예상하고 한두 줄만 바꿔 보세요. 화면 편집 내용은 이 브라우저에 자동 저장됩니다. 브라우저가 저장을 제한하면 저장되지 않을 수 있습니다.

코드는 안쪽 단계마다 두 칸씩 들여씁니다. 한 줄이 길면 가로로 움직여 읽을 수 있습니다. 수정한 코드도 ‘들여쓰기 정리’로 정돈할 수 있으며, 저장해 둔 초안은 자동으로 바꾸지 않습니다.

04. 복습문제

width 200, padding 좌우 20씩, border 좌우 5씩이면 기본 박스의 너비는?

내가 답한 뒤 해설 보기

기본 content-box에서는 200+40+10=250px. border-box라면 테두리까지 200px이다. 바깥 margin은 별도다.
