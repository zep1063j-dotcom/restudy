웹의 동작 구조와 HTML 기초

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차기초 용어·들여쓰기 안내예제만 새 탭에서 열기
기초 정의핵심 정리코드 수정·실행복습문제

01. 핵심 개념

head는 문서 정보, body는 본문. 태그에 속성으로 주소·설명을 붙인다.

02. 실행 흐름

서버에 요청 → HTML 응답 → 브라우저가 문서를 해석한다. 로컬 HTML은 서버 없이도 열 수 있다.

기초부터 천천히 읽기

웹페이지를 읽으려면 먼저 파일과 브라우저를 구분하면 좋습니다. 파일은 내 컴퓨터에 저장한 내용이고, 브라우저는 그 내용을 해석해 화면에 보여 주는 프로그램입니다. HTML 파일을 고치는 것과 브라우저 화면을 보는 것은 서로 다른 단계입니다.

처음 보는 말의 정확한 뜻

파일과 확장자
파일은 저장한 내용의 단위입니다. index.html에서 .html은 웹 문서임을 나타내는 확장자입니다. 파일 이름을 바꾸는 것과 내용 수정은 다릅니다.
폴더와 경로
폴더는 파일을 묶는 공간이고 경로는 파일의 위치입니다. ./는 현재 폴더, ../는 한 단계 위 폴더를 기준으로 읽습니다.
브라우저와 렌더링
Chrome·Safari 같은 브라우저가 HTML·CSS 등을 읽어 보이는 화면을 만드는 과정을 렌더링이라고 부릅니다.
마크업과 프로그래밍
HTML은 내용에 역할을 표시하는 마크업 언어입니다. 반복 계산이나 클릭 처리 같은 동작은 주로 JavaScript가 맡습니다.
DOCTYPE과 lang
<!DOCTYPE html>은 현대 HTML 방식으로 읽도록 알리는 선언입니다. lang="ko"는 문서의 주된 언어가 한국어임을 나타내며 번역이나 화면낭독기에도 도움이 됩니다.
문자 인코딩과 UTF-8
컴퓨터가 글자를 저장·해석하는 규칙입니다. <meta charset="UTF-8">은 한글 등을 UTF-8로 읽게 합니다. 글자가 깨지면 저장 형식과 선언을 확인합니다.
들여쓰기와 중첩
안쪽 내용을 오른쪽으로 밀어 적으면 부모·자식 관계가 보입니다. 들여쓰기 자체가 HTML의 부모를 정하는 것은 아니며 실제 태그가 무엇을 감싸는지가 기준입니다.

기호와 문법을 읽는 법

같은 기호도 문맥에 따라 역할이 달라집니다. 아래 설명은 이 페이지의 예제 기준입니다.

DAY01 기호와 예시
표기뜻짧은 예
< >태그를 감쌉니다.<p>
</ >닫는 태그입니다.</p>
속성="값"설정 이름과 값을 연결합니다.lang="ko"
#이름이 예제 링크에서는 문서 안의 id 위치를 가리킵니다.href="#contact"
<!-- -->사람을 위한 HTML 주석입니다.<!-- 설명 -->

짧은 코드 한 줄씩 읽기

<main>
  <h1>나의 카페</h1>
  <p>커피를 판매합니다.</p>
</main>
  1. 1줄 main은 주된 내용을 감싸기 시작합니다. 4줄 </main>에서 끝납니다.
  2. 2줄과 3줄은 두 칸 안으로 들어가 같은 부모의 자식임을 보여 줍니다. h1은 제목, p는 문단입니다.
  3. 제목 문구만 바꾸려면 h1 태그 사이의 글자를 바꿉니다. 태그의 시작과 끝은 유지합니다.

예상 결과와 전제

화면에는 “나의 카페”라는 제목과 “커피를 판매합니다.”라는 문단이 보입니다. main이라는 글자나 태그 기호 자체는 보이지 않습니다.

아래 실행 편집기에는 실행 가능한 전체 예제가 있습니다. 위 짧은 코드는 개념 설명용 발췌이며, 필요한 주변 코드와 전제를 함께 읽어 주세요.

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

HTML
웹페이지에 들어갈 내용과 그 의미를 표시하는 언어입니다. 제목, 문단, 목록, 링크 등을 태그로 구분합니다.
태그와 요소
<p>소개 문장</p>에서 <p>와 </p>는 태그이고, 두 태그와 그 안의 내용을 합쳐 요소라고 부릅니다. img처럼 닫는 태그가 없는 요소도 있습니다.
속성
태그에 추가하는 설정입니다. <a href="#contact">에서 href는 속성 이름이고 #contact는 그 값입니다.
head와 body
head는 문서 제목·문자 인코딩·스타일 연결 같은 정보를 담고, body는 본문 내용을 담습니다.
요청과 응답
브라우저가 서버에 필요한 것을 요청하면 서버가 파일이나 데이터를 응답합니다. 이 복습 예제는 내 컴퓨터의 파일을 읽으므로 서버 없이 열립니다.
제목과 문단
h1~h6은 제목의 중요도와 계층을 나타내고 p는 문단입니다. 큰 글씨가 필요하다는 이유만으로 제목 태그를 고르지는 않습니다.

꼭 기억할 내용

  • 보이는 문구와 동작을 정하는 속성을 구분하세요. 링크 글자를 바꿔도 href가 같으면 목적지는 그대로입니다.
  • title은 브라우저 탭의 제목이고 h1은 본문 제목입니다. 이 페이지 안의 미리보기 제목은 실행 결과 위에서 확인합니다.
  • HTML의 중첩 관계를 읽으세요. ul 안의 li는 목록의 항목이며, 위치를 바꾸면 화면 순서도 달라집니다.
이 예제의 코드를 읽는 순서
  1. 문서 위쪽의 title을 찾아 예제 이름을 확인합니다.
  2. body 안의 h1과 p를 찾아 화면의 제목·소개 문장과 대응시킵니다.
  3. ul 안의 li 두 개가 메뉴 두 줄을 만드는지 확인합니다.
  4. href="#contact"가 id="contact"인 영역을 가리키는지 연결해서 읽습니다.

자주 헷갈리는 부분

글자를 고치면 링크 목적지도 바뀔까요?

아닙니다. 보이는 글자는 태그 사이에 있고 목적지는 href 값에 있습니다.

HTML만 만들면 주문이 처리될까요?

메뉴와 입력 화면은 만들 수 있지만, 실제 주문 저장이나 결제에는 별도 처리 코드가 필요합니다.

코드를 읽는 순서

  1. <head> 안에는 문서 설정이 있습니다. <title>은 브라우저 탭 제목입니다.
  2. <body> 안이 화면의 본문입니다. <h1>은 가장 중요한 제목이고, <p>는 문단입니다.
  3. <ul>은 순서 없는 목록을 감싸고, 각 <li>가 메뉴 하나를 나타냅니다.
  4. <a href="#contact">연락처 보기</a>에서 글자와 목적지는 다릅니다. #contact는 같은 문서의 id="contact" 영역입니다.
  5. <!-- ... -->는 사람에게 설명하는 주석이며 화면에 나타나지 않습니다.
  6. 여는 태그와 닫는 태그가 무엇을 감싸는지 보고, 바꾸고 싶은 글자나 속성만 먼저 수정해 보세요.

03. 직접 바꿔 보기

h1의 ‘오즈 카페’를 내 가게 이름으로 바꾸세요. 메뉴 이름과 가격도 하나씩 바꿔 보세요.

먼저 결과를 예상하고 한두 줄만 바꿔 보세요. 화면 편집 내용은 이 브라우저에 자동 저장됩니다. 브라우저가 저장을 제한하면 저장되지 않을 수 있습니다.

코드는 안쪽 단계마다 두 칸씩 들여씁니다. 한 줄이 길면 가로로 움직여 읽을 수 있습니다. 수정한 코드도 ‘들여쓰기 정리’로 정돈할 수 있으며, 저장해 둔 초안은 자동으로 바꾸지 않습니다.
