오즈 카페 — 메뉴 카드

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차예제만 새 탭에서 열기

01. 핵심 개념

JSX, 컴포넌트, props, 구조분해, 기본값

02. 실행 흐름

App에서 메뉴별 값을 넘김 → 같은 MenuCard가 서로 다른 내용으로 표시됨

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

컴포넌트 재사용
같은 화면 구조를 가진 함수를 여러 곳에서 호출해 사용합니다. 데이터가 다르면 보여 주는 내용도 달라집니다.
props
부모가 자식 컴포넌트에 전달하는 읽기 전용 입력값입니다.
구조분해
{ name, price }처럼 객체의 속성을 이름별 변수로 꺼내 받는 문법입니다.
JSX의 중괄호
문자열 속성은 따옴표로, 숫자·변수·표현식은 { }로 넣어 읽습니다.
기본값
desc = "오늘의 메뉴"는 desc가 생략되거나 undefined일 때 쓸 값입니다. null에는 적용되지 않습니다.
className
JSX에서 HTML의 class에 해당하는 속성 이름입니다. label의 for는 htmlFor로 씁니다.

꼭 기억할 내용

  • 특정 카드의 가격만 바꿀 때는 부모가 전달하는 price를, 모든 카드 구조를 바꿀 때는 MenuCard의 반환 JSX를 찾습니다.
  • props는 자식이 직접 고치는 값으로 다루지 않습니다. 바꾸는 주체가 어디인지 추적하세요.
  • 소금빵은 desc를 넘기지 않아 기본 설명을 사용합니다.
이 예제의 코드를 읽는 순서
  1. App이 MenuCard를 두 번 사용하면서 서로 다른 props를 넘깁니다.
  2. MenuCard가 받은 name·price·desc를 꺼냅니다.
  3. JSX가 각 값으로 제목·가격·설명을 만듭니다.
  4. 두 번째 카드의 desc 생략이 기본값으로 이어지는지 확인합니다.

자주 헷갈리는 부분

같은 컴포넌트면 항상 똑같은 문구만 보일까요?

구조는 같아도 전달한 props에 따라 내용이 다를 수 있습니다.

price="4000"과 price={4000}은 같을까요?

전자는 문자열, 후자는 숫자입니다. 이후 계산에서 차이가 날 수 있습니다.

실제 React와 JSX를 사용합니다. 로컬에 포함한 React와 변환 도구로 실행하며, 강의의 Vite 설치 절차를 재현한 것은 아닙니다. 화면 편집기에서 JSX도 바꿀 수 있습니다.

04. 복습문제

desc를 생략한 경우와 desc={null}은 기본값이 같을까?

내가 답한 뒤 해설 보기

다르다. 매개변수 기본값은 생략하거나 undefined일 때 적용된다. null에는 적용되지 않으며 null 자체는 JSX에서 글자로 표시되지 않는다.
