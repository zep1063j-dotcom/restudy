DAY 08 / 읽기 · 수정 · 실행

Bootstrap으로 블로그 글 페이지 만들기

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차기초 용어·들여쓰기 안내예제만 새 탭에서 열기
기초 정의핵심 정리코드 수정·실행복습문제

01. 핵심 개념

준비된 CSS 클래스, container·row·col, 반응형 접두사, 모달

02. 실행 흐름

라이브러리 연결 → 클래스에 맞는 스타일 → 모달은 연결된 JS와 대상 id로 동작

기초부터 천천히 읽기

라이브러리를 쓴다는 것은 다른 사람이 준비한 코드의 약속을 이용한다는 뜻입니다. Bootstrap 클래스는 이름만으로 마법처럼 동작하는 것이 아니라 연결한 CSS와 JS가 그 이름을 해석해 기능을 제공합니다.

처음 보는 말의 정확한 뜻

라이브러리
이미 구현된 코드와 기능의 묶음입니다. 가져온 버전과 사용 방법이 현재 프로젝트에 맞는지 확인하며 사용합니다.
CDN
네트워크를 통해 라이브러리 파일 등을 제공하는 방식입니다. CDN 주소를 연결한 예제는 인터넷이 없으면 필요한 파일을 못 받을 수 있습니다.
유틸리티 클래스
여백이나 글자색처럼 비교적 작은 역할을 가진 클래스입니다. 여러 클래스를 조합해 사용합니다.
반응형 클래스
화면 구간에 따라 적용되는 클래스입니다. col-12와 col-lg-8을 함께 쓰면 기본과 넓은 화면의 폭을 구분해 읽습니다.
모달
현재 화면 위에 별도 내용 창을 보여 주는 UI입니다. 실제 구현에서는 열기·닫기뿐 아니라 키보드 포커스 처리도 관련됩니다.
data-* 속성
HTML에 추가 데이터를 넣는 속성 체계입니다. Bootstrap은 data-bs-* 같은 약속을 읽어 특정 동작을 연결합니다.

기호와 문법을 읽는 법

같은 기호도 문맥에 따라 역할이 달라집니다. 아래 설명은 이 페이지의 예제 기준입니다.

DAY08 기호와 예시
표기뜻짧은 예
class="a b"한 요소에 두 클래스를 붙입니다.class="col-12 col-lg-8"
row그리드의 줄 역할 클래스입니다.class="row"
col-12기본 폭을 12칸으로 읽습니다.class="col-12"
col-lg-8lg 구간부터 8칸 폭을 나타냅니다.class="col-lg-8"
data-bs-target실제 Bootstrap에서 대상 요소를 가리키는 설정입니다.data-bs-target="#dialog"

짧은 코드 한 줄씩 읽기

<div class="row">
  <main class="col-12 col-lg-8">
    본문
  </main>
  <aside class="col-12 col-lg-4">
    최근 글
  </aside>
</div>
  1. row가 두 영역을 같은 줄의 항목으로 묶습니다.
  2. main과 aside는 각각 기본 col-12와 넓은 화면용 클래스를 함께 가집니다.
  3. 실제 CSS가 두 클래스를 어떻게 정의했는지에 따라 결과가 정해집니다. 이 예제는 원본 Bootstrap이 아닌 모형 CSS입니다.

예상 결과와 전제

이 복습 모형에서는 좁을 때 위아래로, 600px 이상에서 8:4 비율로 나뉩니다. 실제 Bootstrap의 기본 lg 경계값과 이 모형의 600px를 동일하게 외우지 마세요.

아래 실행 편집기에는 실행 가능한 전체 예제가 있습니다. 위 짧은 코드는 개념 설명용 발췌이며, 필요한 주변 코드와 전제를 함께 읽어 주세요.

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

Bootstrap
미리 준비된 CSS와 일부 JavaScript 기능을 클래스 이름으로 적용하는 UI 라이브러리입니다.
container / row / col
전체 폭을 감싸는 영역, 한 줄, 그 줄 안의 칸을 나타내는 클래스 체계입니다.
12칸 그리드
한 줄의 폭을 12칸으로 생각해 나누는 방식입니다. 8칸과 4칸, 6칸과 6칸 등으로 읽습니다.
반응형 접두사
col-lg-8처럼 특정 화면 구간부터 적용할 폭을 나타냅니다. 실제 경계값은 사용하는 Bootstrap 설정을 확인합니다.
컴포넌트 / 유틸리티
컴포넌트는 모달·카드 같은 UI 구성, 유틸리티는 여백·색·표시 상태 등을 간단히 바꾸는 클래스입니다.

꼭 기억할 내용

  • 이 복습 예제는 실제 Bootstrap이 아니라 클래스 구조를 설명하기 위한 작은 CSS 모형입니다. 실제 라이브러리 전체 동작을 제공하지 않습니다.
  • 모형은 600px부터 두 칸으로 나뉩니다. 실제 Bootstrap의 lg 경계와 같은 값이라고 외우지 마세요.
  • 실제 Bootstrap의 모달이 열리지 않으면 JS 연결과 data-bs-target·id의 일치를 확인합니다.
이 예제의 코드를 읽는 순서
  1. row가 main과 aside를 한 줄의 항목으로 감쌉니다.
  2. 기본 col-12 모형은 각 영역을 전체 폭으로 놓습니다.
  3. 600px 이상에서는 모형의 .col-lg-8과 .col-lg-4 너비가 적용됩니다.

자주 헷갈리는 부분

클래스 이름만 적으면 어디서나 Bootstrap이 될까요?

해당 CSS와 필요한 JS가 연결되어 있어야 합니다. 여기서는 직접 작성한 모형 규칙이 그 역할의 일부를 대신합니다.

버튼 글자를 바꾸면 모달 연결도 바뀔까요?

보이는 문구와 모달 대상 설정은 별도입니다.

로컬 실행에 맞게 일부를 재구성했습니다. 예제 안의 안내에서 실제 라이브러리·서버·파일 모듈과 다른 부분을 확인하세요.

03. 직접 바꿔 보기

본문과 사이드 영역의 width를 각각 50%로 바꾸고 넓은 화면에서 비교하세요. 실제 Bootstrap을 사용한 예제는 아닙니다.

먼저 결과를 예상하고 한두 줄만 바꿔 보세요. 화면 편집 내용은 이 브라우저에 자동 저장됩니다. 브라우저가 저장을 제한하면 저장되지 않을 수 있습니다.

코드는 안쪽 단계마다 두 칸씩 들여씁니다. 한 줄이 길면 가로로 움직여 읽을 수 있습니다. 수정한 코드도 ‘들여쓰기 정리’로 정돈할 수 있으며, 저장해 둔 초안은 자동으로 바꾸지 않습니다.
