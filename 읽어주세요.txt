나의 코드 복습 / DAY01-DAY29

시작 방법
1. 이 폴더의 ‘시작하기.html’을 더블클릭합니다.
2. ‘DAY01부터 시작하기’를 누릅니다.
3. 페이지 안에서 코드를 바꾸고 ‘실행 / 새로 반영’을 누릅니다.

인터넷이나 별도 설치 없이 사용할 수 있습니다. Notion 원본 링크만 인터넷이 필요합니다.
각 DAY 폴더에는 ‘학습.html’과 독립 실행 가능한 ‘예제.html’이 있습니다.

코드를 어디에서 고치나요?
- 가장 쉬운 방법: 학습 페이지 안의 코드 편집기에서 수정하고 실행합니다.
- 파일로 남기기: ‘내 코드 파일로 받기’를 누릅니다. 받은 React HTML은 원래 DAY 폴더에 넣으면 공통 라이브러리를 찾습니다.
- 파일을 직접 편집하기: 각 DAY의 예제.html을 코드 편집기로 열고 수정한 뒤 브라우저에서 다시 엽니다.
- 학습 페이지 안의 수정 내용은 예제.html 파일을 자동으로 바꾸지 않습니다.

진도와 메모
복습 완료 표시, 코드 초안, 메모는 브라우저 저장소에 저장합니다.
브라우저를 바꾸거나 브라우저 데이터를 지우면 기록을 잃을 수 있습니다.
파일 접근에 대한 브라우저 정책에 따라 저장이 제한되면 페이지에 안내가 나옵니다.

확인 범위
강의 개념과 Notion 과제를 바탕으로 새로 만든 연습 코드입니다. 원본의 정답이나 본인 제출물은 아닙니다.
DAY09 및 DAY22-26은 자료를 확보하지 못해 제외했습니다.
DAY08은 Bootstrap 클래스 모형, DAY18은 가상 응답과 데이터 URL, DAY21은 Blob 모듈을 사용합니다.
DAY27-29는 실제 React와 JSX를 사용하되 Vite 설치 없이 실행하도록 로컬 라이브러리를 포함했습니다.
React 패키지는 이 Mac에 이미 설치된 패키지를 읽어 별도 복습용으로 묶었고 원본 프로젝트는 수정하지 않았습니다.
바벨 변환 도구와 라이브러리의 라이선스는 공통/vendor 안에 있습니다.

추천 순서
DAY01부터 차례대로 읽습니다. 코드 전체를 외우기보다 ‘언제 실행되고, 무슨 값이 바뀌며, 어디에 보이는지’를 설명해 보세요.

설명 보강 (2026-11-12)
모든 학습 페이지에 용어와 정의, 꼭 기억할 내용, 예제 코드 읽는 순서, 자주 헷갈리는 부분을 추가했습니다.
기존 페이지를 열어 두었다면 새로고침하면 반영됩니다.

기초 상세 설명과 코드 가독성 보강 (2026-11-12)
각 DAY에 추가 기초 정의, 기호·문법 표, 짧은 코드와 줄별 해설, 예상 결과를 넣었습니다.
00_처음_코드읽기.html에서 파일·브라우저·들여쓰기의 공통 기초를 볼 수 있습니다.
예제.html과 학습 페이지의 시작 코드는 두 칸 들여쓰기와 여러 줄 구조로 정리했습니다.
이미 브라우저에 저장해 둔 내 초안은 유지합니다. ‘들여쓰기 정리’를 누르면 현재 초안도 정돈합니다.
정리 기능은 동작 변경 목적이 아니므로 실행 후 결과도 함께 확인하세요.
