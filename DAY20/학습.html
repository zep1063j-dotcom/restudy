읽은 글 표시하기

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차예제만 새 탭에서 열기

01. 핵심 개념

서버 데이터와 로컬 기록 구분, JSON 저장, 상태별 화면

02. 실행 흐름

저장된 읽음 번호 복원 + 서버 글 목록 요청 → 목록 그림 → 클릭 시 저장 → 새로고침 후 복원

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

localStorage
같은 출처에서 사용하는 브라우저 저장소입니다. 보통 새로고침이나 브라우저 재실행 후에도 남지만 삭제·정책 제한이 있을 수 있습니다.
sessionStorage
탭의 세션에 연결된 저장소입니다. localStorage와 수명이 다릅니다.
키와 값
저장소는 이름인 키와 문자열 값을 연결합니다. 배열을 저장하려면 문자열로 바꾸는 과정이 필요합니다.
setItem / getItem / removeItem
값 저장, 값 읽기, 특정 키 삭제 메서드입니다. 없는 키를 읽으면 null입니다.
복원
저장한 문자열을 읽어 JSON.parse로 값으로 바꾸고, 그 값에서 화면을 다시 만드는 과정입니다.
출처
보통 프로토콜·호스트·포트 조합으로 구분합니다. file:// 저장 동작은 브라우저별로 다를 수 있어 이 페이지에서 직접 확인해야 합니다.

꼭 기억할 내용

  • 변수 ids를 바꾸는 것만으로는 저장되지 않습니다. 저장소에 쓰는 줄까지 실행되어야 합니다.
  • JSON 파싱은 실패할 수 있어 이 예제는 try/catch와 배열 검사로 복원값을 확인합니다.
  • removeItem은 예제 전용 키만 지웁니다. localStorage.clear()는 같은 저장소의 다른 키까지 지울 수 있습니다.
이 예제의 코드를 읽는 순서
  1. 전용 KEY로 저장된 값을 읽고 배열로 복원합니다.
  2. render가 읽음 여부를 화면에 표시합니다.
  3. 읽음 버튼은 중복 없이 번호를 추가하고 JSON 문자열로 저장합니다.
  4. 다시 실행하면 저장값에서 복원하고, 표시 지우기는 키와 화면 상태를 초기화합니다.

자주 헷갈리는 부분

localStorage에 넣으면 다른 기기에서도 보일까요?

계정이나 서버와 자동으로 동기화되는 저장은 아닙니다.

복습 페이지가 저장했다고 하면 원본 파일도 바뀔까요?

브라우저 저장소와 디스크의 HTML 파일은 별개입니다. 파일 보관은 다운로드 기능을 이용하세요.

03. 직접 바꿔 보기

읽음 표시 후 ‘실행 / 새로 반영’을 다시 눌러도 기록이 남는지 확인하세요. 표시 지우기는 이 예제 키만 삭제합니다.

먼저 결과를 예상하고 한두 줄만 바꿔 보세요. 화면 편집 내용은 이 브라우저에 자동 저장됩니다. 브라우저가 저장을 제한하면 저장되지 않을 수 있습니다.

04. 복습문제

변수의 배열만 바꾸고 저장하지 않으면 새로고침 뒤에는?

내가 답한 뒤 해설 보기
