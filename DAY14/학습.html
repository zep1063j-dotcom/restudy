DAY 14 / 읽기 · 수정 · 실행

영화 관람 기록 정리하기

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차기초 용어·들여쓰기 안내예제만 새 탭에서 열기
기초 정의핵심 정리코드 수정·실행복습문제

01. 핵심 개념

map 변환, filter 선별, find 첫 항목, reduce 집계

02. 실행 흐름

배열 → 조건으로 고름 → 필요한 모양으로 바꿈 → 합계·목록

기초부터 천천히 읽기

배열 메서드는 목록을 어떻게 바꿀지 함수로 전달하는 도구입니다. 메서드 이름을 외우기 전에 결과가 “목록인지, 한 항목인지, 합계인지, 참·거짓인지”부터 구분하세요.

처음 보는 말의 정확한 뜻

메서드
값이나 객체에 연결해 사용하는 함수입니다. items.filter(...)처럼 점 뒤에 이름과 괄호가 붙는 형태를 자주 만납니다.
콜백의 매개변수
filter(item => ...)의 item은 현재 처리 중인 항목을 부르는 임시 이름입니다. 변수 이름은 바꿀 수 있지만 본문과 일치해야 합니다.
메서드 연결
filter(...).map(...)은 filter가 만든 결과 배열에 map을 적용하는 순서입니다. 각각 원본에 독립적으로 실행한다는 뜻이 아닙니다.
누적값과 초기값
reduce의 sum은 이전 단계 결과이고 마지막 0은 시작값입니다. 어떤 값에서 출발하는지에 따라 계산 의미가 달라집니다.
forEach와 map
forEach는 각 항목에 작업을 수행하고 자체 반환값은 undefined입니다. map은 각 결과를 모은 배열을 반환합니다.
원본 보존과 객체 변경
map·filter 메서드가 배열 자체를 바꾸지 않아도 콜백에서 item.price를 직접 고치면 원본 객체가 달라질 수 있습니다.

기호와 문법을 읽는 법

같은 기호도 문맥에 따라 역할이 달라집니다. 아래 설명은 이 페이지의 예제 기준입니다.

DAY14 기호와 예시
표기뜻짧은 예
item => ...현재 항목을 받아 결과를 정하는 함수입니다.item => item.price < 4000
.filter(...)조건에 맞는 항목을 고릅니다.items.filter(test)
.map(...)항목별 변환 결과를 모읍니다.items.map(change)
.reduce(...)누적값으로 결과를 모읍니다.items.reduce(sum, 0)
return{} 콜백 본문의 반환값을 정합니다.item => { return item.name; }

짧은 코드 한 줄씩 읽기

const prices = [4000, 3500, 4500];
const selected = prices.filter(price => price <= 4000);
const total = selected.reduce(
  (sum, price) => sum + price,
  0
);
  1. filter는 가격들을 차례로 조건에 넣어 4000과 3500만 남깁니다.
  2. reduce는 0에서 시작해 첫 가격을 더하고 그 결과에 다음 가격을 더합니다.
  3. 괄호 안 줄을 나눠도 하나의 reduce 호출이며, 콜백과 초기값을 쉼표로 구분합니다.

예상 결과와 전제

selected는 [4000, 3500], total은 7500입니다. 조건을 4500 이하로 바꾸면 세 가격이 모두 포함됩니다.

아래 실행 편집기에는 실행 가능한 전체 예제가 있습니다. 위 짧은 코드는 개념 설명용 발췌이며, 필요한 주변 코드와 전제를 함께 읽어 주세요.

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

콜백 함수
다른 함수에 넘겨, 그 함수가 정한 시점에 실행하도록 하는 함수입니다.
filter
조건이 참인 항목만 담은 새 배열을 만듭니다. 개수는 줄어들 수 있습니다.
map
항목마다 변환 결과를 모은 새 배열을 만듭니다. 일반적인 항목 배열에서는 입력과 출력의 항목 수가 같습니다.
reduce
누적값과 현재 항목을 사용해 전체를 하나의 결과로 모읍니다. 합계 외에도 다양한 결과를 만들 수 있습니다.
find / some / every
find는 첫 일치 항목, some은 하나라도 조건에 맞는지, every는 모두 맞는지를 돌려줍니다.
불변성과 참조
새 배열을 만든다고 그 안의 객체까지 모두 새로 복사되는 것은 아닙니다. 콜백에서 원래 객체를 고치는지 주의합니다.

꼭 기억할 내용

  • 원하는 결과의 종류부터 고르세요. 목록 선별은 filter, 변환 목록은 map, 총액은 reduce가 자연스럽습니다.
  • 화살표 함수의 본문에 {}를 쓰면 결과를 돌려줄 return이 필요한지 확인합니다.
  • 빈 배열의 합계를 위해 reduce의 처음 누적값을 0으로 두면 결과가 분명해집니다.
이 예제의 코드를 읽는 순서
  1. price <= 4000인 커피와 빵만 selected에 남깁니다.
  2. selected의 항목에서 name만 뽑아 names 배열을 만듭니다.
  3. 0에서 시작한 sum에 각 가격을 더해 total을 만듭니다.
  4. 이름 목록과 7500원 합계를 화면에 표시합니다.

자주 헷갈리는 부분

map이 알아서 조건에 안 맞는 항목을 빼 줄까요?

항목을 고르는 일은 filter로 분리해서 생각하세요.

filter가 새 배열을 만들면 객체를 직접 고쳐도 원본이 안전할까요?

남은 객체는 원본과 같은 객체일 수 있습니다. 내부 속성의 직접 변경은 원본에도 영향을 줄 수 있습니다.
