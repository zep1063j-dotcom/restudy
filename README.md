# 바이브 코더의 개발 노트

처음 코드를 읽는 사람이 HTML·CSS·JavaScript·Node.js·React·Git을 배우고 작은 웹앱을 수정·검증하는 48개 레슨의 학습 사이트입니다.

## 시작
- index.html을 더블클릭하거나 배포된 기본 주소를 엽니다.
- 첫 수업 시작하기로 공통 기초부터 순서대로 진행합니다.
- 레슨마다 개념·정의·실행 예제·줄별 흐름·수정 과제·정답·오류·메모를 제공합니다.
- Node와 Git 명령은 브라우저 실습과 구분해 터미널에서 수행합니다.

## 바로 실습하기
- downloads/browser-lab.zip: 설치 없는 HTML/CSS/JS 화면
- downloads/node-examples.zip: Node 레슨별 실행 파일
- downloads/cafe-lab.zip: Node API·입력 검증·서버 가격 계산·파일 저장·일반 JS 및 React 화면
- downloads/react-lab.zip: 실제 Vite·React 프로젝트와 빌드
각 ZIP에 README와 실행 순서가 포함되어 있습니다.

## 공개
정적 파일을 GitHub Pages의 배포 소스에 그대로 제공합니다. 첫 파일은 index.html입니다. 쿼리 기반 레슨 주소이므로 임의 서버 라우팅에 의존하지 않습니다. Node 프로젝트는 이 정적 사이트의 API로 자동 실행되지 않습니다.

## 기록
새 기록은 브라우저의 vibe-academy-v2 키에 저장합니다. 기존 vibe-study-* 기록을 자동 삭제하지 않습니다. 내 학습에서 새 기록과 기존 기록을 함께 JSON으로 내보내거나 백업을 가져올 수 있습니다. 브라우저·출처가 바뀌면 저장 공간이 달라질 수 있습니다.

## 범위
입문부터 작은 서비스의 코드 읽기·수정·검증을 위한 과정입니다. 인증·권한·결제·보안 운영·다중 서버·고급 성능과 규모 확장은 별도 전문 설계가 필요합니다. 로컬 학습 프로젝트를 그대로 상용 서비스로 가정하지 않습니다.

## 호환과 출처
이전 DAY별 학습 주소는 새 관련 수업으로 이동합니다. 기존 예제 파일은 보관했습니다. 기존 수업자료 PDF를 완전히 전재한 과정이 아니며, 확인한 수업 개념과 공식 문서를 참고해 설명·예제를 새로 구성했습니다. 각 수업 말미에 공식 참고 문서를 연결했습니다.
