# 바이브 코더의 개발 노트

처음 코드를 읽는 사람이 HTML·CSS·JavaScript·Node.js·React·Git을 배우고 작은 웹앱을 수정·검증하는 48개 레슨의 학습 사이트입니다.

## 시작
- index.html을 더블클릭하거나 배포된 기본 주소를 엽니다.
- 첫 수업 시작하기로 공통 기초부터 순서대로 진행합니다.
- 레슨마다 개념·정의·실행 예제·줄별 흐름·수정 과제·정답·오류·메모를 제공합니다.
- Node와 Git 명령은 브라우저 실습과 구분해 터미널에서 수행합니다.

## 추천 커리큘럼

- roadmap.html: 노베이스에서 작은 앱 수정까지 14단계·핵심 40개·보강 8개 수업
- 각 단계의 수업 링크와 이전·다음 버튼은 추천 학습 순서를 따릅니다.
- assets/data/roadmap.js: 단계 순서·미션·완료 기준
- assets/js/roadmap.js: 단계 목록·이어 배우기·완료 표시

## 바로 실습하기
- downloads/browser-lab.zip: 설치 없는 HTML/CSS/JS 화면
- downloads/node-examples.zip: Node 레슨별 실행 파일
- downloads/cafe-lab.zip: Node API·입력 검증·서버 가격 계산·파일 저장·일반 JS 및 React 화면
- downloads/react-lab.zip: 실제 Vite·React 프로젝트와 빌드
각 ZIP에 README와 실행 순서가 포함되어 있습니다.

## 공개
정적 파일을 GitHub Pages의 배포 소스에 그대로 제공합니다. 첫 파일은 index.html입니다. 쿼리 기반 레슨 주소이므로 임의 서버 라우팅에 의존하지 않습니다. Node 프로젝트는 이 정적 사이트의 API로 자동 실행되지 않습니다.

## 기록
새 기록은 브라우저의 vibe-academy-v2 키에 저장합니다. 기존 vibe-study-* 기록을 자동 삭제하지 않습니다. 내 학습에서 새 기록과 기존 기록을 함께 JSON으로 내보내거나 백업을 가져올 수 있습니다. 브라우저·출처가 바뀌면 저장 공간이 달라질 수 있습니다.

## 범위
입문부터 작은 서비스의 코드 읽기·수정·검증을 위한 과정입니다. 인증·권한·결제·보안 운영·다중 서버·고급 성능과 규모 확장은 별도 전문 설계가 필요합니다. 로컬 학습 프로젝트를 그대로 상용 서비스로 가정하지 않습니다.

## 폴더와 수정할 파일

파일 안내는 [files.html](files.html)에서 표와 함께 볼 수 있습니다.

```text
바이브코딩_복습/
├── index.html              시작 화면 — 이 파일부터 엽니다
├── *.html                  각 메뉴의 화면
├── assets/
│   ├── css/academy.css     사이트 디자인
│   ├── js/academy.js       학습·실행·메모 기능
│   ├── js/glossary.js      용어 분류·검색·상세 설명 표시
│   ├── data/curriculum.js  48개 수업 본문·용어 정의
│   ├── data/solutions.js   수정 과제 정답·풀이
│   ├── data/glossary-notes.js  용어 중심 예시·설명·수정 과제
│   └── vendor/             외부 실행 도구·라이선스
├── projects/               직접 실행하고 수정할 프로젝트 원본
├── downloads/              프로젝트별 ZIP
└── archive/previous-course/ 이전 DAY 예제·공통 파일·기존 PDF
```

처음 코딩할 때에는 downloads에서 프로젝트 하나만 받아 README 순서대로 실행하세요. 사이트 원본과 실습 프로젝트를 한 폴더에 섞지 않습니다. 자세한 수정 위치는 files.html에서 확인합니다.

## 이전 자료와 출처

이전 DAY별 파일은 archive/previous-course에 보관했습니다. 사이트에서 파일 안내를 열면 이전 PDF도 찾을 수 있습니다. 기존 DAY별 온라인 학습·예제 주소는 GitHub Pages의 404 안내에서 새 위치로 이동합니다. 로컬에서 예전 파일이 필요하면 보관함에서 엽니다.

기존 수업자료 PDF를 완전히 전재한 과정이 아니며, 확인한 수업 개념과 공식 문서를 참고해 설명·예제를 새로 구성했습니다. 각 수업 말미에 공식 참고 문서를 연결했습니다.

## 용어 상세 보기

상단 검색은 용어 사전으로 연결됩니다. 용어 이름과 자주 쓰는 표기를 우선 찾고, 없으면 설명에서도 검색합니다. 검색한 용어의 상세 설명·예시·흐름·예상 결과·수정 과제를 같은 화면에서 펼칩니다. 130개 용어는 집중 예시를 제공하며, 나머지는 원래 수업의 설명과 전체 문맥 예제를 함께 표시합니다. 상세 본문은 펼칠 때 구성해 긴 목록의 초기 화면을 가볍게 유지합니다.
