카페 주문 앱을 공통 예제로 삼아 파일 → 화면 → 동작 → 서버 → React → 배포 순서로 배웁니다.

14단계핵심 수업 40개보강 수업 8개권장 4주

하루 60~90분을 출발점으로 잡고, 한 단계에 1~2회 이상 사용하세요. 기간보다 각 단계의 완료 기준을 충족했는지가 다음 단계로 넘어가는 기준입니다.

1번 수업부터 시작 ↗설치·파일 열기 안내48개 전체 수업 찾기

한 번 공부할 때, 이렇게 진행하세요

  1. 10분 · 예측예제를 실행하기 전에 입력·처리·출력을 내 말로 적습니다.
  2. 20분 · 이해정의와 실행 흐름을 읽고, 모르는 용어는 사전에서 찾습니다.
  3. 25~40분 · 수정아래 단계의 미션을 한 가지씩 바꾸며 수행합니다.
  4. 5~20분 · 검증정상·빈 값·경계·실패를 확인하고 diff와 결과를 기록합니다.

막히면 AI에게 오류 문구·관련 코드·기대한 결과·실제 결과를 전달하세요. 설명을 확인한 뒤 작은 변경만 적용하고 다시 시험합니다. 각 단계에 그대로 활용할 질문 예시가 있습니다.

FINAL MISSION / 작은 기능 하나로 확인하기

마지막에는 ‘메뉴 하나 추가’를 끝까지 수행하세요.

새 메뉴를 넣고 화면 표시, 수량 변경, 예상 총액, 서버가 계산한 주문 금액을 차례로 확인합니다. React 프로젝트와 Node 연동 프로젝트는 각각 실행하며, 서버까지 확인할 때에는 cafe-lab의 React 화면을 사용하세요.

  1. 수정할 파일과 데이터의 이동 경로를 먼저 적습니다.
  2. 메뉴의 id·이름·가격을 추가합니다. 서버가 가격을 결정하는 흐름을 유지합니다.
  3. 수량 1·20·0·21과 잘못된 메뉴 id를 시험합니다.
  4. 서버 재시작 후 주문 기록을 확인하고 화면의 성공·실패 안내를 확인합니다.
  5. 변경 diff, 실행한 테스트, 남은 문제를 정리하고 커밋합니다.

완료 기준: 왜 이 파일을 고쳤는지, 클릭부터 저장까지 어떻게 흐르는지, 어떤 입력으로 확인했는지를 직접 설명할 수 있습니다. 로컬 학습 앱의 범위이며 실제 인증·결제·운영 환경은 별도 설계가 필요합니다.
