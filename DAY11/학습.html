DAY 11 / 읽기 · 수정 · 실행

놀이공원 입장료 계산기

이 페이지의 코드는 강의 개념을 바탕으로 새로 구성한 연습 예제입니다.

전체 목차기초 용어·들여쓰기 안내예제만 새 탭에서 열기
기초 정의핵심 정리코드 수정·실행복습문제

01. 핵심 개념

=와 ===, &&·||, if·else if, 삼항식

02. 실행 흐름

입력값 → 조건을 위에서부터 판정 → 맞는 분기 계산 → 결과

기초부터 천천히 읽기

조건문은 값에 따라 다른 길을 고르는 코드입니다. 조건이 어디서 만들어지고 처음으로 참이 되는 분기가 어느 것인지 차례로 따라가면 결과를 예측할 수 있습니다.

처음 보는 말의 정확한 뜻

비교 연산자
<, <=, >, >=, ===처럼 값을 비교해 불리언을 만드는 연산자입니다. =와 ===를 구분합니다.
엄격한 비교
===는 자료형을 자동으로 같게 바꾸지 않고 비교합니다. 10과 "10"은 이 비교에서 다릅니다.
truthy와 falsy
조건식에서 참처럼 또는 거짓처럼 판단되는 값입니다. false, 0, "", null, undefined, NaN 등은 대표적인 falsy 값입니다.
단락 평가
&&와 ||는 왼쪽 값을 보고 오른쪽을 평가할지 정합니다. 그래서 조건뿐 아니라 기본값 선택에도 쓰입니다.
분기와 블록
if의 조건에 따라 실행하는 경로를 분기라고 합니다. {}는 해당 경로에서 실행할 문장들을 묶습니다.
조건의 범위
age < 13과 age <= 13은 13세에서 다릅니다. 포함 여부를 정하는 기호까지 읽어야 합니다.

기호와 문법을 읽는 법

같은 기호도 문맥에 따라 역할이 달라집니다. 아래 설명은 이 페이지의 예제 기준입니다.

DAY11 기호와 예시
표기뜻짧은 예
===값과 자료형을 비교합니다.age === 13
< / <=작은지 또는 작거나 같은지 비교합니다.age < 13
&& / ||조건 결합과 단락 평가에 쓰입니다.member && weekday
!불리언으로 판단한 값을 뒤집습니다.!isLoggedIn
? :조건에 따라 둘 중 한 값을 고릅니다.age < 13 ? 5000 : 10000

짧은 코드 한 줄씩 읽기

const age = 13;
let price;

if (age < 13) {
  price = 5000;
} else {
  price = 10000;
}
  1. age는 숫자 13입니다. price는 뒤에서 재대입할 값이므로 let으로 선언했습니다.
  2. age < 13은 false이므로 첫 블록을 실행하지 않습니다.
  3. else 블록의 price = 10000을 실행합니다. 들여쓰기로 각 분기의 내용이 드러납니다.

예상 결과와 전제

price는 10000이 됩니다. 조건의 <를 <=로 바꾸면 같은 13세에서 5000이 됩니다.

아래 실행 편집기에는 실행 가능한 전체 예제가 있습니다. 위 짧은 코드는 개념 설명용 발췌이며, 필요한 주변 코드와 전제를 함께 읽어 주세요.

먼저 알아둘 용어와 정의

코드 전체를 외우기보다, 각 이름이 무엇을 가리키는지 연결해서 읽어 보세요.

대입과 비교
=는 오른쪽 값을 담는 대입이고, ===는 값과 자료형이 같은지 비교합니다.
조건식
참·거짓에 따라 실행할 분기를 고르는 표현입니다. 비교뿐 아니라 truthy·falsy인 값도 조건 판단에 쓰일 수 있습니다.
if / else if / else
위에서부터 조건을 검사해 처음 맞는 분기를 실행하는 구조입니다.
삼항 연산자
조건 ? 참일 때 값 : 거짓일 때 값 형식으로 두 값 중 하나를 고릅니다.
&& / || / !
둘 다 필요한 조건, 하나만 필요한 조건, 참·거짓 뒤집기에 자주 씁니다. &&와 ||는 불리언만이 아니라 피연산자 값 자체를 돌려줄 수 있습니다.
경계값
조건이 바뀌는 바로 전·정확한 값·바로 뒤의 값입니다. 할인 기준이 15세라면 14·15·16세로 확인합니다.

꼭 기억할 내용

  • 조건의 순서가 결과를 바꿉니다. 넓은 조건이 먼저 맞으면 뒤의 더 좁은 조건에 도달하지 않습니다.
  • 이 예제는 age < 13일 때만 5000원이며 정확히 13세는 10000원입니다.
  • 숫자 변환에 성공했는지와 빈 문자열인지도 먼저 검사합니다.
이 예제의 코드를 읽는 순서
  1. 버튼 클릭 때 age 입력값을 읽습니다.
  2. Number로 숫자로 바꾸고 비어 있거나 잘못된 입력이면 돌아갑니다.
  3. 삼항식이 나이에 따라 가격을 고릅니다.
  4. result의 글자를 선택한 가격으로 바꿉니다.

자주 헷갈리는 부분

if 안에 =를 쓰면 같은지 비교하는 것일까요?

대입이 됩니다. 비교 의도라면 사용하는 연산자를 확인하세요.

두 조건을 ||로 연결할 때 비교식 하나만 쓰면 될까요?

age === 10 || age === 20처럼 각각의 비교를 적어야 합니다. age === 10 || 20은 다른 뜻입니다.

03. 직접 바꿔 보기

할인 기준 age < 13의 13을 15로 바꾸고 14·15·16세를 시험하세요.
